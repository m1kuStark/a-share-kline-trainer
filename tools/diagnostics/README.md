# 诊断工具

这里保存经过审查、可复现的本机诊断工具源码。诊断工具只收集版本、配置字段、端口、服务健康状态和行情目录元信息；不得上传行情文件、个人训练数据库、凭据或完整日志。

## kline-diagnostic-v1

来源：用户提供的 [Kline-Diagnostic.zip](kline-diagnostic-v1/Kline-Diagnostic.zip)，2026-09-22 收录。原ZIP按字节保留，旁边展开[脚本](kline-diagnostic-v1/Kline-Diagnose.cmd)与[原说明](kline-diagnostic-v1/使用说明.txt)便于审查。包中没有朋友生成的诊断报告，不能据此推断具体故障。

实际使用时将脚本复制到已完整解压的训练器目录，与Start.cmd放在一起，再双击；放到无发布包的临时目录会报安装文件缺失，临时目录仅用于隔离测试。不要放入通达信目录或压缩包内直接运行。脚本生成TXT报告；无停止服务、修改配置、删除数据或自动上传动作。报告可能包含本机路径、进程信息和接口错误，分享前必须人工脱敏。原始报告留在本地忽略目录`.data/diagnostics/`，不要提交到Git。

该工具针对v0.3.x默认启动方式：只检查脚本旁的配置和部分环境变量，未完整支持`--config`，没有权威解析器的一致性保证；会额外探测默认8787端口，只限127.0.0.1且禁重定向。无配置文件也会给出排查提示，但启动器允许省略配置，不能把每项提示当作确定故障。可用`--no-open`禁用记事本和等待按键。未修改原工具行为；[审查记录](../../docs/verification/2026-09/LAUNCH-UX-01/report.md)记录验证范围。

后续修改先生成新版本，保留原ZIP指纹。它是排障辅助工具，不是发布包运行时依赖；当前公开源码导出和Windows打包白名单均不包含tools/。要随公开版本交付须单独审查集成。
