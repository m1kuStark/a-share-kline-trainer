# v1.2.7 → v1.3.0 训练数据迁移说明

本工具把旧版本（v1.2.7）的**训练录像**和**训练历史**搬到新版本（v1.3.0）。

- 训练录像存在浏览器里，按第一、二步经导出页打包、再在新版录像库导入；
- 训练历史（训练记录/成交/画线等，存在训练库文件 `trainer.sqlite` 里）由导出页一键产出**训练历史迁移包**，
  在新版「设置 → 从 v1.2.7 迁移」中导入（第三步）。

两部分互相独立，先后顺序随意；每一步都**只读取**旧数据，不会修改或删除任何内容，导出后旧版本仍可照常使用。

## 第一步：在旧版本电脑上导出

1. 把整个 `migrate-v127` 文件夹复制到旧版本文件夹里（和 `Start.cmd` 同一级，即 `kline-trainer-v1.2.7-windows-x64` 文件夹内部）。
2. **先正常退出旧训练器**：在训练器页面点「退出训练器」按钮（或运行 `Stop.cmd`）。
   导出必须在旧训练器关闭后进行；工具会自动检测，未关闭时会明确提示。
3. 双击 `migrate-v127` 文件夹里的 **`导出训练录像.cmd`**。
   - 工具会在旧训练器原来的地址上打开一个「训练录像迁移导出」页面（必须用平时使用旧训练器的**同一个浏览器**）；
   - **录像**：页面列出找到的全部录像（本机录像 + 导入过的分享录像），点 **「导出录像合并包」**，
     浏览器下载一个 `训练录像库-….trainer-recordings.json` 文件——这就是全部录像的迁移包；
   - **训练历史**：页面「训练历史」部分点 **「导出训练历史迁移包」**，
     旧版本文件夹里会出现一个「训练历史迁移-时间戳」文件夹（内含 `trainer.sqlite` 副本与 `迁移清单.json`）；
   - 导出**只读取**旧数据，不会修改或删除任何旧数据；原来的 v1.2.7 仍可照常使用。
4. 页面上的「打包 SQLite 训练库（可选）」是**原始备份**用途（原样复制 db/-wal/-shm 三件套），
   新版导入训练历史只认「训练历史迁移包」（含校验与清单），请优先用上面的按钮。

> 如果打不开导出页、提示端口被占、或页面说找不到录像库：改用文件夹里的
> **`迁移兜底-浏览器控制台脚本.txt`**——保持旧训练器正在运行，在其页面按 F12 打开控制台，
> 把 txt 里分隔线以下的整段脚本粘贴进去回车，同样会下载**录像**迁移包。
> （训练历史迁移包只在导出页提供；控制台兜底不涉及训练库文件。）

## 第二步：在新版本（v1.3.0）导入录像

1. 打开 v1.3.0 新版本；
2. 点左侧「训练录像」进入录像库；
3. 点 **「导入录制」**，选择第一步下载的 `训练录像库-….trainer-recordings.json`；
4. 看到「批量导入完成：成功 N」即完成。导入的录像会列在**「导入的分享录像」**栏目下，回放功能完整可用。

说明：

- 迁移包里若有极旧的录像转换失败，导入结果会如实逐条列出（成功 / 跳过 / 失败），不会静默丢失；
- 同一个迁移包重复导入会自动跳过，不会产生重复录像；
- 单条录像文件（`.json` / `.gz`）也仍然可以像以前一样逐条导入。

## 第三步：在新版本（v1.3.0）导入训练历史

1. 打开 v1.3.0 新版本，进入 **「设置 → 从 v1.2.7 迁移」** 分栏；
2. 点 **「选择迁移清单…」**，选中第一步「训练历史迁移-时间戳」文件夹里的 **`迁移清单.json`**；
3. 页面会先做包体检（文件校验和、计数核对），通过后显示包含的训练/交易数量；
4. 点 **「导入训练历史」**，提示已导入后**重启训练器**即生效（原空库会自动备份保留）。

说明：

- 训练历史只能导入到**尚未使用的空训练库**：当前库已有训练记录时会明确拒绝，不会把两份历史合并；
  如需改用旧历史，请先在「设置 → 数据目录」切换到新的空目录并重启，再导入；
- 新版本**不会自动吸收**任何 v1.2.7 数据，训练历史必须经本迁移包显式导入；
- 旧方式（把 v1.3.0 程序解压到旧版本同一文件夹、原地沿用旧训练库）仍然可用；
  但若已在新位置用过新版并建了训练，请改用本迁移包方式，避免互相覆盖。

## 安全与回滚

- 导出工具对旧数据**只读**；唯一的写入是在旧版本文件夹里新增 `migrate-v127` 工具本身和导出的
  `迁移导出-*` / `训练历史迁移-*` 文件夹；
- 想撤销工具：删除 `migrate-v127` 文件夹与上述导出文件夹即可，旧版本不受任何影响；
- 迁移包是普通文件，可复制、可备份；建议确认新版本导入成功后再清理；
- 新版本导入训练历史前会保留原空库备份（`.pre-migration-时间戳.bak`），确认无误后可自行删除。
