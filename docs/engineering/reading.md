# 渐进读取

规则沿待改文件的祖先AGENTS读取；知识从模块README选主题。AGENTS补局部约束，README说明何时读，正文解释一个问题。客户端自动注入不确定时显式读取，不递归读所有子目录。

局部任务直接进入模块；确定下一步或阶段状态才读status；历史仅在追因或确认来源时读。用rg按符号/规则ID/任务ID检索，再读相关段落。同会话未变材料不重复整份载入。

| 任务例子 | 路线 |
|---|---|
| 数据发布失败 | 根规则→server/data规则→publication→对应实现及测试 |
| 分隔条拖动 | 根规则→web/components规则→interaction→pane-resize旅程 |
| M3阶段冻结 | status→M3阶段卡→关联验收与用户决定 |

根AGENTS约2000字符/100行、局部1500字符/60行、索引约2000字符，主题通常2000～5000字符。阈值用于警示，不截断硬约束或错误证据；长历史不默认读取。不要以超长单行绕开预算。

目录按真实主题渐进创建，不预建空树；没有独立约束就不加AGENTS，没有导航选择就不加索引。统一AGENTS.md和README.md命名。

修改跨模块合约要扩展到依赖公开边界；不确定是否满足规格时登记差距，不能让旧历史或代码注释覆盖用户要求。
