# 并行开发约定

先从完整已提交基线创建任务分支和worktree；当前主干名main。每任务记录基础SHA、允许路径、依赖、验收和交接提交，不在同一目录切不同分支。公共合约、迁移、锁文件及图表事件入口由明确owner协调。

worker只写任务范围及自己的任务卡/证据。先集成公共契约，再并行消费者；同改engine或图表宿主的任务串行或先拆边界。集成人一次组装一个含最新main的候选，通过现有测试及主代理视觉门禁后推进到实际测过的提交；main变化则重组重测。

代码回滚用revert保留历史；数据库迁移要兼容和受控备份恢复。代码Git隔离不等于端口、个人库、构建或浏览器存储隔离。当前自动隔离启动器尚未实现，所有Journey由集成人串行负责，详见[DEV-01](../work-items/tasks/DEV-01.md)。

本次文档迁移在已有开发分支按互斥路径分工，完成前保留未提交功能并做源码指纹核对；今后新功能以迁移后的完整提交为起点。更多工程改造仍是[待定提案](../proposals/engineering-parallel.md)。
