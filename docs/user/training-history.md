# 历史训练与成绩单

训练结算后，可以回看结算方式、初始资金、最终权益、收益率和逐笔成交。这些内容来自本地训练数据库的持久记录，只读展示，不会重算账户。下列能力按当前 V1.1.1 源码候选说明，包与验收状态见[当前状态](../status.md)。

## 在哪里看

- 左侧栏「历史」进入历史训练；训练结束的结算面板上也有「查看历史成绩单」直达。
- 列表按结算日从近到远排列（同一结算日按创建先后倒序），每页最多 20 条，用「上一页 / 下一页」翻页。
- 点击任意一行打开成绩单浮窗；右上角“关闭成绩单”是唯一关闭出口，深色和浅色模式随训练器主题切换。
- 每行右侧可删除记录；也可勾选多条记录批量删除。删除前会显示确认提示，取消不会改动记录。

## 列表里能看到什么

- 每行：股票代码/名称、训练周期（或自定义范围类型）、训练区间、结算方式、最终权益、收益率、成交笔数。
- 结算方式两种：**到期结算**（持有到计划结束日）和**提前结算**。这只是结算方式的标注，不代表数据完整性的认证。
- 个别行如果显示「不可认证」（悬停可见原因），说明这局的历史数据存在缺口（例如旧版不复权训练或规则记录损坏），不能作为可靠成绩参考；其他行不受影响。
- 最终权益取自结算当天的持久权益记录；它通常不等于最后一笔成交后的剩余现金（持仓市值也计算在内）。

## 成绩单里能看到什么

- 事实信息：结算方式、训练区间、结算日、初始资金、最终权益、总收益率、交易笔数、复权方式。
- 本局规则：用标签展示创建时冻结的费用、T+1 和成交口径；旧训练仍保留迁移记录标识。
- 逐笔成交：序号、日期、买卖方向、价格、股数、金额、费用。零成交的训练如实显示 0 笔；没卖完的持仓按已记账权益展示，不会虚构平仓。
- 收益率曲线：按训练区间内的持久权益点绘制，训练收益率用红色；底部是日期轴，右侧是百分比轴，悬停显示日期和对应曲线的收益率。
- 同期指数：可勾选上证指数（蓝色）和国证 2000（橙色），在同一主图叠加比较；两项分别控制对应曲线，取消后该指数消失。数据缺失时说明原因，不用训练曲线冒充指数。
- 只读 K 线复盘：显示止于结算日的行情、B/S 成交标记和已保存画线；画线不再单独列成脱离行情的清单，也没有编辑入口。

## 训练进行中为什么看不到历史

只要有一笔训练在进行中，历史查询会暂时关闭，页面提示"结束当前训练后可查看历史"。这是为了避免旧局里相同股票的记录泄漏当前局的未来行情。经左侧「训练」可随时返回当前训练；结算或放弃后历史自动恢复。

已放弃的训练不计入历史列表；录像库（左侧「录像」）与本页相互独立，导入的离线录像仍只用于回放观看。

## 常见问题

- **最终权益和最后一笔卖出后的现金对不上？** 正常：最终权益=现金+持仓市值（按结算日权益点），不是末笔现金。
- **某行显示不可认证或成绩单打不开并提示规则/权息缺失？** 该局历史数据不完整，按提示保留记录、新建训练即可；不影响其他局。
- **成绩单提示画线数据损坏？** 其余事实（资金、成交、收益率曲线）仍正常展示，复盘画线暂不可读；数据不会被自动改写。
