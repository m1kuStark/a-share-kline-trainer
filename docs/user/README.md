# 用户指南

A股K线训练器读取本机通达信日线，供你练习逐日判断、买卖和画线。所有买卖都发生在模拟账户里。

安装和首次配置见[安装与配置](install.md)；费用与 T+1 默认设置、本局规则和旧训练兼容见[训练规则与费用](training-rules.md)；结算后的历史训练与只读成绩单见[历史训练与成绩单](training-history.md)；录制、回放与分享见[录制说明](recording.md)；遇到问题先查[常见问题](troubleshooting.md)。

本指南描述当前公开的 v1.2.7 Windows 便携包（以及同版本源码运行）。录像入口在左侧“训练录像”，录制默认开启；本机训练录像与导入分享录像在录像页分栏显示，来源相互独立。

## 一次训练的完整流程

1. **创建训练**：在「股票代码」「股票名称」任一框输入（支持拼音首字母，如 GZMT → 贵州茅台），从下拉选择或输完整代码/名称自动匹配；清空任一框即可重选。选周期档（1M/3M/6M/1Y/2Y）后起始日自动从最新数据日回退对应时长（可手动修改，保留到下次切换周期）；「自定义范围」直接选择起始日和结束日，系统按可用交易日校验，不接受未来或反向日期。设定初始资金（默认100万，可改）。训练从起始日开始，你只能看到起始日及之前的行情。
2. **推进行情**：默认收盘模式按空格推进到下一个交易日。创建时选择“开盘 + 收盘”后，按“当日开盘 → 当日收盘 → 下一交易日开盘”推进；开盘阶段不会显示当天完整 K 线。周期档和自定义范围都支持该模式，并保留创建时选择的条件单开关。
3. **买卖**：普通单按当前阶段价成交：开盘阶段按开盘价，收盘阶段按收盘价。按 `B` 买入、`S` 卖出；买入按总权益计算买入金额并向下取整到100股（整手），默认T+1（当天买入次日才能卖出）。默认不计手续费；费用与 T+1 默认可在侧栏「设置」调整，只影响新训练，见[训练规则与费用](training-rules.md)。
4. **画线与观察**：随时在图上画线辅助判断，画线按训练保存。
5. **结算**：可以提前结算、持有到计划结束日自动结算，或放弃这笔训练。到期时如果本地数据还没覆盖到结束日，训练会等待你更新数据；已结算的训练不会自动重开。

同一时间只有一笔进行中的训练，开新训练前需要先结算或放弃当前训练。

## 快捷键与图表操作

| 按键 | 作用 |
|---|---|
| 空格 | 推进下一阶段；收盘模式下推进下一交易日 |
| B / S | 买入 / 卖出 |
| ↑ / ↓ | 放大 / 缩小K线 |
| ← / → | 移动十字光标 |
| Home | 恢复默认视图 |
| `]` / `[` | 切换 日→周→月 周期（反向切换） |
| Delete | 删除选中的画线 |
| Esc | 退出画线模式或画线多选 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做画线（Ctrl+Y 也可重做） |

- 观察周期可切日/周/月；推进仍按创建时选择的收盘模式或开盘/收盘两阶段模式执行。
- 指标：MA、VOL、MACD。K线为红涨绿跌，阳线空心、阴线实心。
- 主图空白处向右框选放大、向左框选缩小；滚轮平移历史，价格轴滚轮缩放纵轴；VOL/MACD 区域双击可最大化。

输入文字、编辑弹层打开或正在画线时，快捷键会被隔离，不会误触发交易。

## 画线工具

图表工具栏提供23种画线，包括线段、价位线、价格通道、斐波那契、几何图形、箭头和文本。

- 新画线默认为黄色1px虚线；颜色、粗细、线型、端点价格都可以编辑，支持多选、移动、撤销/重做/清空。
- 画线保存在训练数据库里，与这笔训练绑定，重启后仍在。
- 显示方式在创建训练时锁定（默认前复权）。发生分红送转后，已有画线会自动换算到新的前复权价格；但**早期版本保存、缺少基准信息的画线会按原值显示，不做自动换算**，如位置不对可手动调整。

## 行情数据从哪来

先在通达信下载日线和权息数据，再回训练器点“更新日线”。该按钮只重新扫描本地文件，不联网下载，也不修改通达信文件。目录与文件清单见[安装说明](install.md)。

## 退出训练器

左侧栏底部的“退出”按钮提供**保存并退出**：它会先等待本页画线、录像等保存完成（保存失败可重试或取消），如果有其他训练器页面打开，会在那些页面上弹出确认框——全部确认后才真正退出；任何页面拒绝或限时未响应都会取消退出，服务继续运行。退出过程会关闭数据写入、等待在途请求完成、正常关闭数据库后再停止进程，页面显示“训练器已退出”即表示端口已释放。

退出不会结算或放弃进行中的训练，进度原样保留；下次启动后继续，无需先结束本局。

日常用完点“退出”即可；`Stop.cmd` 保留为**应急强制结束**兜底（身份核验后直接结束进程，不等待页面保存），只有在页面无法使用时才需要它。关闭浏览器标签页不会停止服务——这是有意设计：浏览器无法可靠区分刷新、崩溃和休眠，因此“关闭最后一个标签页自动停止服务”经评估暂不启用，退出请使用上述按钮。

## 数据存放在哪里，如何备份

训练器的数据分两处，备份需要两边都考虑：

- **训练数据**：Windows 发布包默认在解压目录下的 `data`；源码运行默认在 `%USERPROFILE%\.a-share-kline-trainer`。在页面“保存并退出”，确认停止后复制整个发布包目录中的 `data`。自定义数据库须一并保留同名 `-wal`、`-shm` 文件，详见[备份说明](troubleshooting.md#备份前先停止训练器)。
- **训练录像**保存在浏览器的 IndexedDB 里，按访问地址和安装实例区分。录像页将本机训练与导入分享分栏展示，可单条删除或按来源清理；清理浏览器数据、换浏览器、换端口都会让已存录像“看不见”，重要录像请先导出（见[录制说明](recording.md)）。

数据库备份不含录像。录像含回放所需的行情、操作、画线和训练状态，但导入后只供观看，不会恢复可继续操作的训练。完整备份需要两者。

## 升级与移动

- 升级前先在旧版本页面“保存并退出”，再解压新包并复制原来的 `trainer.config.json` 与 `data` 目录；不同解压目录默认使用相互独立的数据。页面无法使用时才用旧目录的 `Stop.cmd`。
- 尽量保持端口（默认8787）、浏览器和原训练数据库不变。录像库还使用数据库中的固定标识隔离来源；复制原 `data` 可保留该标识，新建空数据库会使用新的录像库。更早版本的共享录像请先在旧版本导出，再到新版本导入。
- 桌面快捷方式指向解压目录里的 `Start.cmd`，移动或重命名该目录后需要重新创建快捷方式。

## 成绩、排行与设置

- 侧栏「历史」查看已结算训练，点击记录打开成绩单浮窗，右上角关闭；列表支持确认后单条或手动勾选批量删除。收益率曲线可叠加上证指数和国证 2000，共用日期轴和百分比轴，鼠标悬停查看对应日期的数值。
- 「排行」按 1M/3M/6M/1Y/2Y 分组，完整周期与提前结算分别排列；自定义范围独立展示，只有起止日期都相同的训练才放在一起。行业视图需显式提供通达信 56 行业目录，缺失时显示不可用，不猜测股票归属。排行记录也打开同一成绩单浮窗。
- 可查看总收益率、最大回撤、胜率、盈亏比和沪深300超额，缺失指标如实显示不可用。右上角未连接通达信时，点击「连接通达信」直接打开 Windows 原生目录选择器；选择期间页面操作被阻断，取消不改配置，确认有效目录后自动保存并连接。
- 成绩单提供止于结算日的只读 K 线、B/S 标记与已保存画线复盘。存在运行中训练时，历史及排行查询会阻止查看其他局，避免提前泄露行情。
- 「设置」保存新训练的费用、T+1、初始资金与复权默认值，也提供自动检查日线开关和通达信目录查看、校验、保存入口。目录保存后重启生效，失败保留原选择；详见[训练规则与费用](training-rules.md)和[安装与配置](install.md)。

当前版本支持可选的开盘/收盘两阶段推进和条件单；训练仍使用本地通达信日线数据，不提供真实在线行情来源。
