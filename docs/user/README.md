# 用户指南

A股K线训练器在本机运行，用你自己的通达信日线数据做逐日行情训练：像看盘一样逐日推进K线，练习判断、下单和画线，结束后查看这笔训练的结果。程序完全离线，不联网获取行情，不提供投资建议，也不是券商交易软件——所有买卖都只发生在训练里。

安装和首次配置见[安装与配置](install.md)；录制、回放与分享见[录制说明](recording.md)；遇到问题先查[常见问题](troubleshooting.md)。

## 一次训练的完整流程

1. **创建训练**：明确选择一只股票、一个观察区间（1M/3M/6M/1Y/2Y）、起始日和初始资金（默认100万，可改）。训练从起始日开始，你只能看到起始日及之前的行情。
2. **逐日推进**：按空格推进到下一个交易日，图表加载当天的K线。
3. **买卖**：按当日收盘价成交。按 `B` 买入、`S` 卖出；买入按总权益计算目标仓位并向下取整到100股（整手），默认T+1（当天买入次日才能卖出）。费用默认关闭，创建时可开启。
4. **画线与观察**：随时在图上画线辅助判断，画线按训练保存。
5. **结算**：可以提前结算、持有到计划结束日自动结算，或放弃这笔训练。到期时如果本地数据还没覆盖到结束日，训练会等待你更新数据；已结算的训练不会自动重开。

同一时间只有一笔进行中的训练，开新训练前需要先结算或放弃当前训练。

## 快捷键与图表操作

| 按键 | 作用 |
|---|---|
| 空格 | 推进到下一交易日 |
| B / S | 买入 / 卖出 |
| ↑ / ↓ | 放大 / 缩小K线 |
| ← / → | 移动十字光标 |
| Home | 恢复默认视图 |
| `]` / `[` | 切换 日→周→月 周期（反向切换） |
| Delete | 删除选中的画线 |
| Esc | 退出画线模式或画线多选 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做画线（Ctrl+Y 也可重做） |

- 观察周期可切日/周/月，但推进粒度恒为一天。
- 指标：MA、VOL、MACD。K线为红涨绿跌，阳线空心、阴线实心。
- 主图空白处向右框选放大、向左框选缩小；滚轮平移历史，价格轴滚轮缩放纵轴；VOL/MACD 区域双击可最大化。

输入文字、编辑弹层打开或正在画线时，快捷键会被隔离，不会误触发交易。

## 画线工具

提供23种画线：线段、射线、直线、水平直线/线段/射线、垂直直线/线段/射线、平行直线、价格通道线、斐波那契线、画笔、价位线、矩形、圆圈、圆弧、箭头线、看涨箭头、看跌箭头、百分比线、诅咒线、文本。

- 新画线默认为黄色1px虚线；颜色、粗细、线型、端点价格都可以编辑，支持多选、移动、撤销/重做/清空。
- 画线保存在训练数据库里，与这笔训练绑定，重启后仍在。
- 显示方式在创建训练时锁定（默认前复权）。发生分红送转后，已有画线会自动换算到新的前复权价格；但**早期版本保存、缺少基准信息的画线会按原值显示，不做自动换算**，如位置不对可手动调整。

## 行情数据从哪来

程序只读取你本机通达信目录里的日线和权息文件（只读，不会修改它们），包括：

- `vipdoc\sh\lday\`、`vipdoc\sz\lday\` 下的日线文件（`*.day`）
- `T0002\hq_cache\` 下的权息文件 `gbbq` 和证券名称文件

这些文件需要你用自己的通达信客户端先下载好。训练器里的"更新日线"只是重新扫描这些本地文件，**不会联网下载任何行情**。新的交易日数据要在通达信里下载后，再回到训练器更新。

## 数据存放在哪里，如何备份

训练器的数据分两处，备份需要两边都考虑：

- **训练数据**（训练、成交记录、画线）保存在数据目录下的 SQLite 数据库里，默认是 `%USERPROFILE%\.a-share-kline-trainer\trainer.sqlite`。备份数据库请先停止训练器服务再复制文件（只关闭浏览器页面不算停止服务）。
- **训练录像**保存在浏览器的 IndexedDB 里，按访问地址（`127.0.0.1:8787`）区分。清理浏览器数据、换浏览器、换端口都会让已存录像"看不见"，重要录像请先导出（见[录制说明](recording.md)）。

两边各有分工：数据库备份不含录像；导出的录像自带回放所需的行情、操作、画线和当时的训练状态，但它只是回放数据——导入后只能观看回放，不会把里面的训练恢复成可继续操作的训练，也写不进训练数据库。完整备份请两边都做。

## 升级与移动

- 升级到新版本：先停止旧版本正在运行的服务，再解压新的发布包，把原来的 `trainer.config.json` 复制到新目录即可；默认数据目录不变，训练数据自动沿用。
- 尽量保持端口（默认8787）和浏览器不变，否则训练录像会按新的访问地址分开存放。
- 桌面快捷方式指向解压目录里的 `Start.cmd`，移动或重命名该目录后需要重新创建快捷方式。

## 当前版本未包含

以下功能在计划中但**尚未实现**，界面上对应入口为禁用状态：完整的成绩排行与指标成绩单、复盘分析、设置页。不要依据任何宣传或截图假定这些功能可用。

训练器也不会自动交易、不会给出买卖建议；它只帮你复盘和练习自己的判断。
