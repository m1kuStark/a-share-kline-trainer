# 录制、回放与分享

训练器可以在你训练时录制操作，用于事后回放、复盘和分享给别人观看。录制完全在本机进行，**不会自动上传任何内容**；是否导出、发给谁，由你自己决定。

## 录制什么

每笔新训练默认开始录制，训练页顶部持续显示录制状态，可随时暂停/恢复。

- 记录：买入、卖出、被拒绝的委托，画线和文字标注的增删改，以及按交易日排列的推进时间轴。
- 不记录：界面主题、画线工具的选择、图表加载等界面操作。
- 暂停期间发生的事不会补录；恢复录制时会保存一份完整的当前状态快照，所以回放时暂停区间会如实显示为"未记录"，不会伪造连续的操作。

训练结束后默认保留本机录像历史；如果你在结束时选择丢弃，只会删掉这一轮的录像，不影响这笔训练的成绩和画线。保存失败会明确提示，不会假装成功。

## 录像来源与清理

录像库按当前安装实例隔离，页面分成两个来源栏：

- **本机训练**：当前安装实例中完成或保存的训练录像。正在训练、或仍被其他训练器标签页写入的录像会受到保护，不能被清理。
- **导入分享**：从 `.trainer-session.json.gz` 或旧版 JSON 导入的只读录像。导入项使用独立存储 ID，不会伪装成本机训练，也不会写入训练历史数据库。

每一栏都可以删除单条录像，也可以清理该来源的全部可删除录像。清理前会显示确认提示；导入分享栏的清理不会影响本机训练栏，本机训练栏的清理也不会删除导入分享。重要录像请先导出保存。

## 回放

侧栏“训练录像”打开录像库，可查看本机训练或导入分享录像并逐步回放：

- 回放按交易日推进：空格推进到下一日，PageUp / PageDown 前后一日；也可以用播放按钮自动逐日播放，速度按"秒/日"调节（0.2 到 10 秒，见播放控件）。
- `]` / `[` 可独立切换回放中的 日/周/月 观察周期，↑ / ↓ 缩放、← / → 移动十字光标、Home 恢复视图；都不影响当前正在进行的训练。
- 回放是只读的，不会重复产生成交或修改账户。

## 导出与分享

在训练页点击“导出录制”，或在训练结束、结算弹窗中选择导出，会得到一个压缩文件（`.trainer-session.json.gz`）。分享包自带回放所需的已见行情、权息、训练规则、初始状态，以及逐日操作、画线和当时的训练状态。**接收方导入即可观看，不需要和你有相同的通达信目录或数据**。录像库另有「全部导出」，可把本机训练与导入分享一起保存为 `.trainer-recordings.json` 集合文件，适合备份或换机；进行中训练的最新片段先从训练页导出。

- 分享由你手动导出，程序不会自动上传。
- 未完成训练的分享只包含到导出时为止已可见的行情，接收方回放到那里为止。
- 导出的文件里包含你的操作记录和对应的行情数据，分享前请自行确认内容合适。

## 导入

在录像库中导入分享文件或旧文件：

- 支持当前的 `.trainer-session.json.gz` 压缩格式。
- 支持录像库「全部导出」生成的 `.trainer-recordings.json` 集合；批量导入后在导入分享栏选择录像播放。
- **旧版本导出的 JSON 文件仍然可以导入**，导入后原有存储保留，不会被覆盖。
- 导入的录像只进入录像库用于回放：回放是只读的，导入**不会**把里面的训练恢复成可继续操作的训练，也不会写入你的训练数据库。
- 导入有大小限制：当前格式压缩文件约 25MiB、解压后约 128MiB；旧版 JSON 的迁移上限约 256MiB。超限或格式无效的文件会被拒绝，并且不会影响你现有的训练和录像。

## 存放位置与注意事项

- 录像主要保存在**浏览器的 IndexedDB**；桌面版使用自己的内置浏览器存储，ZIP 版使用打开它的 Edge/Chrome 存储。按访问地址和训练数据库中的固定录像标识隔离；换端口、浏览器、浏览器配置文件或新建数据库，可能显示另一份录像库。
- 桌面版在结束训练并保留录像的相应出口，会额外写入 `<数据目录>\recordings`。浏览器版没有这个本地文件归档能力；进行中、暂停和导入的录像也不能假定已经归档。归档失败时按提示手动导出。
- 清理浏览器存储、卸载、换电脑或换浏览器前，先「全部导出」并保留原文件。自动归档文件存在不代表整个录像库已备份。
- 训练成绩、成交、进度和画线在 SQLite 数据库里；完整备份需要数据目录和录像导出两部分。操作步骤见[用户指南](README.md#数据存放在哪里如何备份)。
