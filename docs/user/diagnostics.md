# 诊断与反馈（本地操作日志）

遇到 bug 或需要反馈问题时，训练器提供两种本地诊断材料。全部只保存在你的电脑上，**不会自动联网上传**。

## 操作日志

- 位置：数据目录下的 `logs/operations.log`（默认 `%USERPROFILE%\.a-share-kline-trainer\logs\operations.log`）。
- 内容：页面按钮/标签点击（只记标签文字，不记输入框内容）、页面错误、业务接口调用（方法/状态/耗时，参数已脱敏）、启动与版本信息。
- 不记录：密码/令牌、完整本机路径（只保留末段名称）、训练备注/复盘文字、键盘输入的字符。
- 保留：单文件最大 2 MiB，保留 4 份后自动滚动清理；可直接删除目录内文件，程序会自动重建。
- 打开方式：桌面版「设置 → 关于与更新 → 打开操作日志目录」；或手动进入上述数据目录的 `logs` 文件夹。

## 复制诊断信息

桌面版「设置 → 关于与更新 → 复制诊断信息」会生成一段纯文本：版本、平台、数据目录、更新通道与最近检查结果、最近错误、主日志尾部。不含训练与交易数据，可直接粘贴到 Issue/反馈中。

## 反馈建议

1. 先复制诊断信息；
2. 打开操作日志目录，按问题发生时间挑选对应文件（无需全部提供）；
3. 描述复现步骤、预期与实际结果；
4. 不要附上训练数据库、真实交易数据或通达信目录内容。

## 隐私

操作日志属于本机诊断数据，不参与任何训练数据校验或云同步；是否提供给维护者由你决定。
