# 主图均线设置

本页说明自定义 MA 功能的源码候选，尚未随公开安装包发布。使用者指南入口见[用户指南](README.md)。

## 调整均线

点击主图右上角「MA 设置」打开参数面板。正在画线时，先退出画线模式再打开。

- 最多设置八条均线，每条可选择周期和颜色。周期须为 0～1000 的整数，0 表示关闭该条均线；开启的周期不能重复。全部设为 0 可隐藏所有 MA。
- 周期表示当前图表的 K 线根数：例如 MA20 在日线中是 20 根日 K，在周线中是 20 根周 K，在月线中是 20 根月 K。日、周、月共用同一份配置。
- 可以选择「默认 25/60/144」「常用 5/10/20/60」或「中长 20/60/120/250」，再手动调整。选择组合和「恢复默认」只修改面板草稿。
- 点击「应用」保存并更新均线，保留当前图表位置与画线。点击「取消」、关闭按钮或按 Esc 放弃本次修改。

默认显示 MA25、MA60、MA144，其余五条关闭。MA 按图表收盘价计算简单移动平均：最近 N 根 K 线的收盘价之和除以 N。历史不足 N 根时，不显示对应的均线数值；切换到周线或月线后，可用根数较少，长周期均线可能暂不显示。

默认配置保持原有加载量。启用更长周期时，按需要补充更早历史，保留图表位置与画线；补载失败会显示「均线历史加载失败，点击重试」。补载期间历史不足的位置暂不显示数值。已保存的长周期配置在刷新或切换观察周期后按其实际需要加载，不固定加载最大周期的历史。

## 保存与回放

配置保存在当前访问地址的浏览器本地存储中，刷新后保留。更换浏览器、端口或清理站点数据后，需要重新设置。保存失败时面板会提示错误，本次配置不会应用。

均线是观察偏好，不改变训练的交易规则、进度或结算结果。当前回放使用观看时的均线偏好，录像不保存和精确还原录制时的均线设置。
