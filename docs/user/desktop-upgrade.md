# 桌面版安装、迁移与升级

适用当前 Windows 桌面安装版。安装程序与训练数据分开存放；从旧 ZIP 转入时，需要同时处理训练历史和浏览器里的录像。

## 首次安装

到 [Releases](https://github.com/m1kuStark/a-share-kline-trainer/releases) 下载 `kline-trainer-desktop-setup-v<版本>-windows-x64.exe`，按向导安装，再从桌面或开始菜单打开。首次使用选择本机通达信目录。v1.3.0 不再提供桌面便携 exe，ZIP 版仍可作为免安装兜底。

桌面版默认数据目录是 `%USERPROFILE%\.a-share-kline-trainer`。旧数据本来就在此处时会继续使用；安装器不会扫描或自动吸收各个 ZIP 文件夹里的 `data`。显式配置过路径时，以实际配置为准。

## 从 v1.2.7 ZIP 迁入

1. 先按[完整备份步骤](README.md#数据存放在哪里如何备份)保留旧训练数据和录像。从 [v1.3.0 发布页](https://github.com/m1kuStark/a-share-kline-trainer/releases/tag/v1.3.0) 下载 `migrate-v127.zip`，完整解压。
2. 把整个 `migrate-v127` 文件夹放到旧版 `Start.cmd` 同级，正常退出旧训练器，再双击工具里的 `一键迁移.cmd`。使用原来存录像的浏览器，等待「一键导出完成」。
3. 把整个工具文件夹连同导出文件复制到新版安装目录，与 `K线训练器.exe` 同级。退出新版后，再双击同一个 `一键迁移.cmd`；按提示等待历史合并、录像导入完成。
4. 在新版「历史训练」核对训练与成交，打开一局查看画线，再从「训练录像」播放一局。确认前保留旧目录与备份。

完整操作和失败处理见工具随附的[迁移说明](https://github.com/m1kuStark/a-share-kline-trainer/blob/main/tools/migrate-v127/static/迁移说明.md)。导入录像只恢复回放；可继续训练的进度需要数据库。不要用旧数据库直接覆盖已经产生新训练的数据库。

## 日常更新

在「设置 → 关于与更新」检查版本，按提示下载、保存并退出、安装重启。更新程序沿用数据目录；退出不会自动把进行中的训练结算为历史。更新前先做一次完整备份。

ZIP 版更新仍走自己的通道。存量桌面便携 exe 若提示更新源缺少便携产物，改用桌面安装器；当前公开发布不提供便携 exe 的原地更新产物。

## 备份与卸载

完整备份是**停止程序后复制数据目录，加上导出的录像文件**。桌面版的 `recordings` 自动归档未必包含进行中或导入的全部录像。具体备份、恢复与核对步骤见[用户指南](README.md#数据存放在哪里如何备份)。

当前源码的交互式卸载会询问是否删除默认训练数据目录：选「否」保留，选「是」删除该目录，里面的自动归档也会被删除。升级中的静默卸载保留此目录。旧安装包可能没有同样的询问，以实际提示为准；卸载前应另存录像导出与数据备份。

排障见[常见问题](troubleshooting.md)，ZIP 与源码步骤见[安装与配置](install.md)。
