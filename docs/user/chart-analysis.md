# 行情条与区间统计

## 常驻行情

图表左上方显示日期、开高低收和涨幅。默认取最近已知K线；移动十字光标立即跟随其指向的K线，移出图表后恢复默认。鼠标悬浮信息卡保留原有延时。**日K** 的行情条、时间轴刻度、底部状态条的日期都带中文星期（如 `2026-04-15 周三`）；周K/月K 不显示星期。

日线涨幅按本根收盘相对上一根日线收盘；周/月线对应显示周/月涨幅，不能当作单日涨幅。缺前收显示`--`。开盘阶段默认显示最近已形成K线，日期可能是前一交易日；不把当前开盘价伪装成当日完整OHLC。随机时间模式日期继续遮蔽，揭示后按既有日期口径换算。

## Shift 两点区间测量

在主图按住 Shift，**单击起始 K 线**，再**单击结束 K 线**，会形成一个覆盖两根 K 线之间所有 K 线的 Select Box，并弹出数据窗口。窗口包含：

- 起点/终点的日期与收盘价、涨跌幅、价差、K 线数量（含首尾）；
- 区间涨跌幅、区间最高价/最低价（含对应日期）、区间振幅；
- 总成交量/成交额、上涨/下跌/平盘 K 线根数。

**拖动 Select Box 左/右边界**（边界位于起止 K 线中心，与十字线竖线一致）可调整起止 K 线，数据窗口会实时更新；这样可以直接量出一段 K 线区间的表现，而不再是脱离 K 线的自由两点。周/月线按当前周期根数统计。Esc、普通单击、滚轮、窗口失焦、切换周期或数据更新都会清除测量。

两点测量是临时展示，不写训练、画线或录像，只读回放同样可用。绘图取点、多选模式、Ctrl/Alt/Meta 组合、坐标轴与分隔条优先，不会误触发测量；多空反转开启时数据窗口仍按真实价格计算。

## 测量工具（一键进入）

顶栏「测量」按钮（在「划线」旁）是测量工具的开关：点一下进入测量模式，光标变成十字，图上提示「测量模式：拖动或两次点击选择起止K线，Esc 退出」，按钮高亮。进入后不用按 Shift：

- **拖动建立**：在主图按住左键，从起点 K 线拖到终点 K 线松开。拖动过程中只会看到不断变长的 Select Box 预览，松开后才弹出数据窗口。
- **两次点击建立**：第一次单击起点 K 线，出现虚线竖线提示；第二次单击终点 K 线，弹出数据窗口。
- 反方向拖/点（先终点后起点）会归一为同一区间；可以继续拖动 Select Box 的左右边界调整起止 K 线，数据窗口实时更新。
- 在测量模式里再次拖动或点两下会直接建立新测量（替换旧的），不必先关掉。

退出：再点一次「测量」按钮，或按 Esc（一步退出模式并清除当前测量）；切换周期、结束训练、选择画线工具或进入多选模式也会退出并清除。滚轮/缩放/平移、窗口失焦只清除当前测量，测量模式保持，可以直接继续下一次测量。

测量模式与画线取点、多选互斥；分隔条、价格轴、底部时间轴拖动、Ctrl/Alt/Meta 组合优先；测量期间空格推进、B/S 买卖、Delete 删除画线被隔离。测量属于临时展示：不写训练、画线、撤销史或录像，不重载行情、不改变视窗；回放页仍沿用 Shift 两点测量；开启多空反转时数值仍按真实价格计算。

## 区间统计

在主图绘图区空白按住右键横向拖选，松开后点击“区间统计”；也可以先在空白右键点击“区间统计…”，再用左键拖选。允许从右向左选、选择一根K线，统计范围包含首尾。只统计已加载的K线，拖出边界会钳制，不额外取行情。

统计窗口提供根数、起止日期、起始开盘/结束收盘、最高/最低及其日期、涨跌额/幅、振幅、相对基准最高/最低涨幅、总/平均每根成交量与成交额、上涨/下跌/平盘根数。成交量按100股为一手显示，成交额按万元显示；缺失数据用`--`，不伪造零。缺历史流通股本，累计换手率不可用。

- 涨跌基准优先取所选首根前一根收盘；缺少有效前收时取首根开盘，窗口明确说明。
- 涨幅＝`(末根收盘/基准-1)×100%`；涨跌额＝末根收盘－基准；振幅＝`(区间最高-区间最低)/基准×100%`。
- 上涨/下跌/平盘根数按每根收盘与其前收比较；缺前收的根单独列出，不把阴阳线当涨跌。
- 周/月线按当前周期统计；形成中周/月只包含推进日之前已知数据。价格采用图表已有复权口径。

Esc取消选择或关闭窗口；弹层隔离交易、推进和删除快捷键。统计属于临时展示，不保存为画线，不改变视窗，不写录像；只读回放也能使用。绘图取点右键仍结束绘图，图形右键仍编辑/删除；副图、坐标轴和分隔条不启动统计。

交互参考[通达信官方功能说明](https://help.tdx.com.cn/function.html)中的区间统计能力；这里明确列出本应用的数据与公式边界，未宣称逐项复制通达信未公开公式。

## 编译与测试缓存

构建输出通常在仓库的`web/dist`、`server/dist`，旅程独立构建/数据库/截图在`.runs/run-*`，依赖及Vite缓存在`node_modules`内。Windows的npm下载缓存默认可能位于`%LOCALAPPDATA%/npm-cache`，系统/浏览器临时文件默认使用`TEMP`、`TMP`，所以仓库在D盘时C盘仍可能产生缓存。

如需将可控缓存定向到D盘，在启动构建/测试的同一个PowerShell中设置：

```powershell
$taskTemp = 'D:\Ktrain-build-cache\temp'
New-Item -ItemType Directory -Force $taskTemp | Out-Null
$env:TEMP = $taskTemp
$env:TMP = $taskTemp
$env:npm_config_cache = 'D:\Ktrain-build-cache\npm'
$env:TRAINER_DB = Join-Path $PWD '.data\development.sqlite'
npm run build
```

临时目录选择在仓库之外，避免隔离工程测试误识别父级项目。设置只影响当前终端及其子进程，不迁移已有缓存。系统日志或浏览器自身的其他文件仍可能写入系统盘；不保证C盘完全零写入。个人训练库不作为测试夹具。

## 多空反转开启时的口径

开启主图「多空反转」后，K 线按镜像价显示，但**常驻行情条、区间统计和两点测量仍显示真实价**（与订单/悬浮卡等决策信息一致）：

- 行情条的日期、开高低收与日/周/月涨幅始终是真实值。
- 区间统计以真实序列计算：涨跌基准、振幅、最高/最低价、涨跌幅都是真实价口径。
- 两点测量的起终点价按鼠标位置先反镜像回真实价再展示，因此可能与图上直观的镜像价位不同；价差与涨跌幅也按真实价计算。
