1. **【修订七】** 一切画线交互与视觉元素限训练主界面内：画线本体、右键菜单、文本编辑面板、选择框等 HTML 层元素锚定 `.chart-wrap` 并钳制边界，不得侵入菜单栏/信息栏/训练控制台。

3. **【修订十】** 不新增程序化缩放路径；既有 `restoreYAxisAutoFit` 四路径（框选右滑/左滑、zoomBy、resetView）不动。
4. **【M2 零回归】** 每单元提验前跑 M2 冒烟：框选双向缩放、滚轮平移/价格轴滚轮纵轴缩放、↑↓←→Home、双击副图放大还原、主题切换、B/S 标记与成本线渲染——全部保持不变。
5. 引擎标记 `bsMark`/`costLine` 保持 `ignoreEvent` 纯渲染层，不参与画线交互与持久化。
6. klinecharts 钉定 10.0.3；涉及库内部结构的写法（如现有 `barSpaceLimit` hack）须同等谨慎并注释依赖，升级需复查。

## 三、核心设计

### 3.1 三态模式机（画线与框选缩放共存的关键）

| 模式 | 行为 |
|---|---|
| `default` | M2 现状：框选缩放／滚轮平移／十字光标，行为完全不变 |
| `draw:<tool>` | 选中某画线工具后：自研框选手势在 `onPointerDown` 直接 return（框选不误触），画线交由 klinecharts overlay 机制；**Space/B/S 热键禁用**（防误推进/误交易）；状态条显示"画线模式：××（Esc 退出）" |
| `select` | 选择模式：拖橙色选择框批量选中画线，Delete/右键删除 |

- Esc 或再次点击当前工具＝退回 default；绘图进行中右键＝取消绘制（不弹菜单）。
- 画线完成后**不自动进入选中态**（规避上轮"拖动平移与刚绘制线段内置选中态冲突"遗留项）。
- 全局热键：Delete（删除选中画线）、Esc（退出画线模式/取消绘制）；文本面板输入期间由既有 `isTyping()` 排除冲突。

### 3.2 工具清单与工具栏分组

| 分组 | 工具 | 实现方式 | 单元 |
|---|---|---|---|
| 线类 | 线段 / 射线 / 直线 | 内置 segment / rayLine / straightLine | D2~D4 |
| 水平系 | 水平直线 / 水平线段 / 水平射线 | 内置 | D5~D7 |
| 垂直系 | 垂直直线 / 垂直线段 / 垂直射线 | 内置 | D8~D10 |
| 通道测量 | 平行直线 / 价格通道线 / 斐波那契线 / 画笔(折线) | 内置（画笔若库无内置则自定义多点折线） | D11~D14 |
| 几何 | 价位线 priceLine（水平射线＋起点黄底价位标签）/ 矩形 / 圆圈 / 圆弧（三点定弧、支持逆时针） | **自定义 overlay** | D15~D18 |
| 标注 | 箭头线（线段＋末端实心箭头）/ 看涨箭头 / 看跌箭头 / 文本（含编辑面板） | **自定义 overlay** | D19~D23 |
| 测量 | 百分比线（两点间五档水平线组） | **自定义 overlay** | D22 |
| 功能按钮 | 撤销 / 清空 / 选择模式 / 吸附开关（关→弱→强循环，默认弱；强＝磁吸开/高/低/收四价，用库原生 magnet） | — | D24/D28/D29 |

- 自定义 overlay 共 9 个：矩形、圆圈、圆弧、文本、百分比线、价位线、看涨箭头、看跌箭头、箭头线（B/S 点与成本线 M2 已有，不计入）。
- 默认样式：用户画线统一**默认黄色**，深浅两主题下均可读；选中高亮单列样式。
- 工具按钮随所属单元逐个出现在工具条上，未交付工具不可见。

### 3.3 交互增强（上轮 12 条重整后的落点）

- 吸附三态开关 → D24；hover仅cursor:pointer，不加粗/变色（按用户后续决定，命中几何见当前实现）→ D25；右键菜单（编辑价位＝**行内小输入框**仅改纵坐标，弃用 window.prompt；删除画线）→ D26；左键拖动整体平移（x 按 bar 对齐、y 按值差，拖动中 `setScrollEnabled(false)`）→ D27；选择模式框选批量删除 → D28；撤销/清空 → D29；文本编辑面板（多行/颜色/字号/加粗/斜体/确定取消，HTML 层位于 chart-wrap 内）→ D23；画线选中与删除基础（点击选中＋Delete）随首个工具落地 → D2。

### 3.4 持久化设计（D30/D31）

- **服务端**：`db.ts migrateDatabase()` 新增 drawings 表（`training_id INTEGER PRIMARY KEY`、`payload TEXT(JSON)`、`updated_at`）；`api.ts` 新增 `PUT/GET /api/trainings/:id/drawings`——训练不存在 404、payload 非数组 400、体积上限 256KB，错误沿用既有 HttpError/setErrorHandler 模式。
- **前端**：`chart.getOverlays()` 序列化（排除 bsMark/costLine 引擎标记），1.2s 变化防抖 PUT＋`beforeunload` keepalive 兜底；打开训练/刷新时 GET 后逐条 `createOverlay` 重建。
- 画线与训练状态无关：进行中与已结算训练均可画，按 training_id 持久化。
