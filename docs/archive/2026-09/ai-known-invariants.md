# 不变量与已知未修项（Known Invariants）

> 违反任何一条即视为回归。新增不变量须在本文件登记并配断言。

## 硬性不变量（配断言）

1. **klinecharts 钉定 10.0.3**（package.json + lockfile）。内部 API 依赖清单见 architecture.md 登记表，升级逐项复查。
2. **红涨绿跌国内口径**：蜡烛红涨绿跌＋阳空阴实、VOL 红涨绿跌、最新价线方向色（priceMark.last 三键，相对前收）、theme.ts 显式覆盖。
3. **防未来**：训练 K 线不含推进日之后数据；训练中 /api/kline 返回 409（full-acceptance 断言）。
4. **交易规则**：T+1 拒当日卖、整手 100 股、按当日收盘价成交、买入仓位按总权益（单测对账）。
5. **复权基准滚动**：前复权基准=推进日；历史成交价用chartPrice，当前成本线使用含position_events的账户成本（当前基准不再复权该成本），禁止仅以原始成交股数重放历史复权买价。
6. **画线锚定 timestamp+value**：禁止 dataIndex 锚定；兼容 forward 前插（禁止补偿滚动）。
7. **交互模式互斥**：画线取点/框选缩放/多选框选/纵轴缩放/画线拖拽由 KlineChart 事件入口守卫链集中裁决；多选模式下框选不缩放 K 线。
8. **主图操作与视觉元素限训练主界面**（修订七）：框选矩形/右键菜单/编辑面板锚定 chart-wrap 并钳制边界。
9. **引擎标记不可选中**：bsMark/costLine 保持 ignoreEvent，不参与画线选择/拖拽/持久化。
10. **画线默认样式常量同源**：1px 虚线黄 dashedValue[4,4]，全局 theme 与编辑应用两处必须引用同一值。
11. **热键矩阵**：Space 推进、B/S 交易、↑↓ 缩放、←→ 十字光标、Home 复位、Delete 删画线、Esc 退出模式；`]`周期增序循环、`[`减序循环。输入/编辑/自定义不触发周期切换，未完成画线禁 Space/B/S/周期切换。
12. **端点价位回显两位小数**（按价格精度）。
13. **自动保存不改变布局**：待保存/保存中/失败/重试/成功只更新固定状态栏；不得改变工具区、账户区尺寸或滚动位置。
14. **工具自定义隔离**：仅自定义模式允许拖入/移出/重排常用工具；常用配置跨刷新恢复，自定义期间禁用交易热键和绘图。
15. **主代理视觉验收**：每次 Bug 或开发交付后，核查深浅主题、桌面尺寸、控件空间、文本溢出和状态变化；子任务实现不免除主代理最终 UI/UX 验收责任。
16. **成交标记避让**：B/S 不绘制在主副图和时间轴上；独立标记条、稀疏横坐标保持、密集同方向聚合无覆盖，详情可查。
17. **实际显示上限**：840根为真实可视范围限制，不能只钳制计数文本；新尺寸稳定后仍需符合。
18. **透明价位样式**：新工具价位标签共用对象颜色和透明背景，不能重新引入默认填充。
19. **分隔条最高优先**：主图/VOL、VOL/MACD分隔条的原生7px区域优先于框选、多选、轴缩放和画线；一次分隔拖拽持续到松手/取消，不能改变柱宽。
20. **成本同步**：买卖/推进返回账户快照时同步更新成本；即使后续行情读取失败，清仓不能残留成本线。配股实际缴款计入持仓取得成本并以cost_delta持久化。
21. **顶部紧凑与日期明确**：当前日期常驻、次要详情浮层不挤动主图；日K标可见末日，周/月标周期，不能把周一起点误称截止日。顶部控件空格保持原生操作、不触发全局推进。
22. **数据尾等待守卫（目标，仍有缺口）**：无下一根且不能证明目标股票已完整覆盖计划区间时，保持 running 返回"等待日线数据"；全市场末日不能单独证明该股停牌或无漏数；既有 settled 不重开不延长。当前实现仍有全市场尾/仅源尾推断分支，见 DATA-02，不能作为本不变量已满足的证明。
23. **目录失败不清缓存**：市场目录读取失败不得当作空目录；删除缓存只依据成功且完整的扫描；真不存在（absentMarkets）与暂不可读（failures）必须可区分。
24. **数据版本原子发布（目标，尚未完全满足）**：目录、日线版本与权息全部准备成功后再一次发布；失败/超时保留已发布旧版本。当前只有 `data_file_state`＋日志在同一事务，目录和权息独立提交，协调器未检查 catalog failures；实例内任务合并不覆盖其他 API 的刷新入口。见 DATA-01/04。
25. **needsUpdate 仅建议性**：数据状态按钮的"需更新"是跳过周末的启发提示（节假日可能建议性误报，文案兜底），不得作为结算、推进或数据完整性的依据。
