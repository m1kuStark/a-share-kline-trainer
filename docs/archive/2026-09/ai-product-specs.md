## 核心口径（验收追认＋修订决策）

| 口径 | 内容 |
|---|---|
| 交易 | 当日收盘价成交；T+1；整手 100 股；买入仓位按总权益（受现金约束取整到手）；费率可开佣金万 2.5 最低 5 元＋卖出印花税 0.05% |
| 权息 | 分红入现金/送转加股/配股足额自动缴款，实际认购款增加持仓取得成本并记cost_delta；历史成交价用chartPrice换算 |
| 成本线 | 当前持仓加权取得成本=剩余costTotal/当前股数（含送转）；部分卖出按比例结转、清仓后成本重置；现金分红仅记现金。前复权当前基准日无需再次调整成本；成本线与账户同源 |
| 复权 | 默认前复权，创建时锁定；基准滚动到推进日（防未来） |
| 可见历史 | 840 同屏最大可见根数（非加载总量）；初始最多1040（840＋200暖机）；缩放1~840；动态历史forward前插，窗口变宽仍执行上限 |
| 排行 | 收益率→最大回撤→胜率三级字典序；提前结算打标单独分组 |
| 双盲 | 移出 V1（手动选股下隐藏名称无意义）；V2 候选＝随机股票＋随机时间真盲测 |
| 画线 | 工具链范围见 docs/M3-画线工具链-开发计划.md（D1~D32 单元）；默认 1px 虚线黄色 dashedValue[4,4]；多选标识为黄芯白圈锚点，线体保留用户颜色；文本不做绝对定位 |
| 编辑 | 颜色/粗细(1~5px)/样式(实线/虚线/点线)/端点价位（两位小数，不编辑横坐标）；多选选项卡式批量编辑 |
| 交互补充 | 水平射线沿第二点方向延伸；圆圈按直径两端点确定正圆；hover 只改变 cursor；折线右键结束、Esc 取消 |
| 文本 | 颜色/字号/多行/粗斜体，锚点保留图表坐标；靠边换行及避让，极长内容缩小后仍超出时省略显示，完整文本保留可编辑 |
| 保存 | 按 training_id 保存至 SQLite；256 KiB、500 对象、单对象 256 锚点；窗格使用 candle_pane/VOL/MACD 语义键；自动保存失败保留本地待保存副本 |
| 常用工具 | 用户可在自定义模式拖入、移出、排序并保存本机浏览器偏好；其他工具单独折叠。状态栏固定占位，自动保存不得挤动工具和账户区 |
| 测量标签 | 百分比线与斐波那契线统一显示价位和比例，透明无填充；密集文字避让，离屏价位不显示标签，保留图例空间 |
| 诅咒线 | 先高点、后低点；保留两锚点，第二点时间起向右延伸，纵坐标是两点均价，只显示50%射线及透明价位标签 |
| 价位线 | 与测量线共用透明价位文字，默认黄色并跟随对象颜色；成本文字也不使用填充 |
| 成交标记 | 橙底白字B、天蓝底白字S，在图表下方独立40px窄条；稀疏成交对齐时间，密集同向聚合，悬停显示明细 |
| 深色模式 | 主图、VOL、MACD和标记条为纯黑；面板、按钮和选项卡使用中性灰；浅色主题保留 |
| 周期快捷键 | `]`日→周→月→日，`[`反向；输入、弹出编辑、自定义和未完成绘图期间隔离 |
| 副图尺寸 | 原生分隔条7px命中带优先于框选/多选/轴缩放，拖拽期间只调整相邻pane高度，柱宽保持不变；纵轴文字宽度变化可带来极少量边缘K线数变动 |
| 顶部空间 | 全局28px、行情操作38px、动态状态20px，桌面图表顶部约92px；当前日期常驻，起始/计划结束/时长/复权收进详情浮层，不保留大标题和常驻快捷键说明 |
| 数据末日 | 单独显示实际可见末根日期，必要时同时标出已载入末日；横轴稀疏/外推刻度不代表数据截止。刷新读取当前训练边界内本地文件，回到最新K线仅重置视图，不推进交易 |
| 日线更新（已有首批实现） | 首页/训练页同一“更新日线”入口；启动及窗口激活检查状态，手动触发扫描；TDX仅同步已下载离线文件。无变化不重画，失败保留旧图，训练日/账户/画线不变；数据一致性剩余差距见status |
| 数据源适配（扫描合约已有，训练读取待解耦） | 目标为统一目录/原始日线/权息/基准/覆盖范围/修订合约，先包装TDX，后续接真实非TDX来源；当前DailySource仅覆盖扫描，测试假来源不代表真实来源接入完成 |
| 设置规则（待开发） | 交易规则和来源创建时固定，默认设置只影响新训练；补旧训练兼容，防止当前全局费用/T+1读取导致规则漂移 |

## 页面四区域（修订七，硬性规则）

菜单栏（左）｜信息栏（上）｜训练主界面（中，主图＋副图）｜训练控制台（右）。**主图一切操作及其视觉元素不得越出训练主界面**；画线工具条停靠训练控制台底部（用户 D1 反馈改定）。

## V1 边界（明确不做）

后复权/等比复权、涨跌停与流动性模拟、分时/分钟数据、多训练并行、多账户、双盲遮蔽。

## V2 候选

其余指标、等比复权、分钟级推进、战法统计（交易归类胜率）、CSV 导出、随机股票＋随机时间真盲测模式。
