## 审查修正

首次只读审查指出两个实际缺陷。窄视窗中相邻 K 线可共用一个 CSS 像素：不能用这一像素反查成交所属 K 线。旧几何在碰撞夹具返回空；终版对已披露的有序行情二分查找，并要求时间戳完全相等，像素只负责绘制和裁剪。几何回归 3/3，包含共用像素与缺失数据两个方向。

训练和回放中，成交点按钮获得焦点后，Space 原先冒泡为「推进」，没有切换按钮。两页前测（`run-d392445e-fba6-4371-a6fa-19ed3e01f2bc`）均因 `aria-pressed` 仍为 false 失败。终版只在此按钮截住 Space 的 keydown 冒泡，保留浏览器原生按钮激活。测试同时检查显示状态、训练日期与推进请求、回放首日的位置。
