## 前测与反例

- 真实 Edge 前测（`run-70411c16-794b-48b8-af22-6e61dc87d0f4`）：切到浅色，DIF 仍绘成 `#f2f2f2`。当时的断言按名义背景 `#fbfcfb` 算出 1.089:1，低于 4.5。旧测试的背景来源本身也存在误差。
- 独立复核发现训练副图底色其实是 `#f7f9f8`，回放才是 `#fbfcfb`。终版判据读取图例所在 Canvas 背后实际的不透明背景，而不是主题变量；检测同一绘图区中图例与非水平、非垂直曲线使用同色。
- 临界色变异（`run-3e1857d0-f85d-4af8-aa56-66645d787ac4`）：仅在隔离浏览器中将 DIF/K 真正绘为 `#747474`。原判据按回放底色会算出 4.545:1，终版在训练底色算出 **4.420:1**，用例按预期失败，exit 1。变异未留在源码。
- 若仅在首次挂载设色而不更新已挂载的副图，深→浅检查会留下深色的白线；若主题更新波及 MA，用户在界面选的 `#123456` 将不能从真实 MA 实例原样读回。
