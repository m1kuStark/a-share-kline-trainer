# 设计契约与取舍

目标使用者在 Windows 桌面反复创建训练、看图推进、下单和复盘。当前界面已有颜色及图标规范；本轮价值应体现在任务分区、空间利用、动作可达和连贯反馈，不能仅统计替换了多少 token。

## 工作台

创建页采用并列的「标的与区间」和「本局规则」，底部独立开始区。保持股票→周期→日期的既有认知顺序，经典初始资金仍与日期同行，随机维度仍拥有固定条件槽。相比把常用参数藏入折叠面板，并列布局无需额外展开；短窗口允许局部滚动，主要动作留在可见区域。内容过长或放大文字时可滚动而不裁切。

历史页的大屏保留横向比较，最小桌面将行内信息分组。标签、数值、次要说明和危险操作区分层级；成绩单入口可通过键盘到达，子控件操作不触发整行动作。训练工作区保持图表为中心，不改变副图布局或引入新的交易/画线模式切换。

## 视觉与动效

延续现有深色纯黑图表、灰色面板，以及浅色中性灰绿表面和青蓝交互色。红涨绿跌、买卖色和 Odometer 偏好沿用已有语义。Windows 系统字体保持本地可用，无字体下载；页面标题、分区标题、正文与数值依职责调整空间，避免过量大标题占用图表。

| 事件 | 呈现与行为 | 减少动效 |
|---|---|---|
| 创建/历史/排行/录像导航 | 新内容短淡入，旧页立即卸载，既有保存协议不变；不等离场动画 | 直接显示 |
| 设置/确认/成绩单进入 | 遮罩淡入，面板短距离进入；立即可操作 | 直接显示 |
| 关闭与取消 | 立即移除、立即恢复焦点，避免不可见遮罩继续阻挡 | 相同 |
| 选中/hover | 仅颜色与边框轻过渡，不缩放整个点击目标 | 即时颜色变化 |
| 推进、交易、保存状态 | 业务即时；固定区域承载反馈，不等待装饰 | 相同 |
| 数字滚动 | 继续既有 trainer_odo_motion 逻辑 | 不被新规则覆盖 |

120/180ms 为本候选呈现默认，不是平台标准。验证状态始终分为机器断言、root 视觉判断和用户体验验收。

## 候选身份

基线为 `6d557a12f400ce45b50418b8556f943d39fef754`。所有浏览器证据使用 run manifest 中独立构建与数据库。最终产物记录提交、构建资源 SHA256 和实际加载资源，预览、NSIS安装包、公开版本各自核验。不能用旧 B5 截图证明本轮候选，也不能用源码变更证明安装包更新。

## 实际最小内容区补验

隔离 unpacked Electron 实测外框1024×680对应内容1008×641、DPR=1（packaged-runtime.json）。此前1024×680浏览器用例不能证明该内容预算。root实UI发现买入按钮底部456px超过console底部424px，默认绘图面板从432px开始并挡住按钮。独立预期由操作关系给出：默认交易与画线同时可达，买卖按钮完整处于console可视区域，按钮中心真实命中；图表仍为主区域且连续推进不移动目标。修复前补正式RED，修复后在实际尺寸、原尺寸和大桌面复跑，不缩减已有图表预算。

## 长错误反馈补验

固定保存区应保持按钮位置，同时允许完整阅读错误和恢复建议。root在run-e922cd57中先取得RED：1008×641内容区内，错误首字符top=538.625而反馈容器top=552，负方向内容无法滚回。根因为48px反馈区用flex居中放置超高段落。改用安全居中：短反馈仍居中，溢出时从起点排布并局部滚动；不改变错误文字或保存语义。回归同时检查首尾字符、真实滚轮位移和保存按钮位置。
