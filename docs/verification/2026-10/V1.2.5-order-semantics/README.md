# V1.2.5 条件单触发语义修订验证

候选工作树：`wt/integration/v1`。基线为 v1.2.4 候选 `896c1d5`。本记录描述工程自验，不代表用户验收或 GitHub 发布。

## 用户反馈（v1.2.4 人工测试）

挂出多笔买入限价（触发价高于市价）后，价格未到触发价，只要推进到下一日条件单就自动成交。

## 根因

v1.2.0 起条件单按经典限价/止损矩阵触发（v0.4 设计文档语义表）：触发方向由 side×order_type 推导——"买入限价"的触发条件是 `low ≤ trigger`。市价低于触发价时挂单属于"立即可成交"，任何一根 K 线的 low 都满足条件，因此每次推进立即成交。引擎实现与旧规格一致，是**规格语义与用户"到价才触发"预期冲突**，不是编码缺陷。

## 修订（V1.2.5）

- 触发方向在挂单时按触发价与当前阶段价的相对位置冻结：高于市价＝'up'（等待上触）、否则＝'down'（等待下触）；存入 `orders.trigger_direction`（迁移新增列，旧行 NULL 按经典矩阵推导，行为不变）。
- 限价/止损只区分成交价口径：限价按触发价成交，跳空越过且限价不可成交（买：open > trigger）时当日不成交保持挂单；止损按当日收盘价成交（跳空按开盘价），含自然滑点。
- 界面：提交前实时提示等待方向与成交口径；挂单列表与标记悬浮层显示"上触/下触"。
- 设计文档 v0.4 条件单撮合语义表已同步修订。
