## 本轮修复

1. 快速连续点击被库当作双击，吞掉下一工具的首点或提前完成图形；现对独立取点重置库点击累计。
2. 折线右键结束残留选中、撤销后 Delete 失效；现完成库进度迁移并清理选中状态。
3. 靠近右下边缘的文本被截断；现显示和命中共用窗格内布局，长内容换行或缩小。
4. 新文本尚未确认就被指针事件写入历史/自动保存；现排除待确认文本。
5. 旧周线或历史加载请求覆盖新周期；现按请求/数据版本丢弃过期响应。
6. 关页时排队请求无法可靠完成；现同步保存本地副本，服务端确认后只清除对应版本。
7. 当前未完成周/月 K 的画线横坐标偏移；现库周期与实际图表周期一致。
8. 主图无限直线的不可见延长部分被副图框选命中；现先按所属窗格裁剪选择范围。
9. 混合选中文本改色无效；现文字属性映射至 extendData，批量编辑与单条一致。
10. hover 引起的库排序变化误占用撤销历史；现快照按 id 固定顺序。
11. 水平工具分别改两个价位可能破坏水平约束；现只有一个可编辑价位，同步所有端点。

新增 Vue 严格类型检查并纳入构建，修正库声明不一致的使用方式、无效样式键及图表卸载方式。klinecharts 的 manifest/lockfile 均固定 10.0.3，内部依赖已登记。

## 使用边界

- 水平射线沿第二点方向延伸，左右均可；圆圈以两端点为直径，始终显示正圆。
- 文本锚点仍是图表坐标；靠边时仅移动文字布局。极长文本在最小可读字号仍超出窗格时显示省略号，完整内容仍可编辑。
- 单次画线数据上限 256 KiB、500 个对象、每个对象 256 个锚点；保存失败有状态和重试入口，本地副本保留。
- 保留已有的轴标签时间后缀和向数据尾部空白区平移行为；这些不影响防未来的数据截断。
- 这是 Windows 桌面工具，已有布局最小宽度 1100px；本轮不声明移动端验收通过。
- 未提交、推送或冻结 M3。用户整体验收通过后再确定阶段冻结。

## 复跑与验收

在仓库目录运行 `npm run verify:m2`、`npm run journey`。Journey 后执行 `npm run build:web` 恢复普通生产前端，再以 `npm start` 启动。

用户可以重点检查工具操作手感、线条和文本的视觉效果、复杂图形的编辑，以及连续绘制和撤销。结算后选择“继续查看图表”仍可画线，地址中的训练编号用于刷新重开；“返回首页”清理该上下文。
