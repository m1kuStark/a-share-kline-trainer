## 4. 新发现的缺口和后续风险

1. **数据尾误结算（R0 优先）**：`server/src/train/engine.ts` 的 advanceTraining 在找不到下一根时直接 settled，缺少覆盖到期判断。等待新数据不能成为完整成绩，旧 settled 训练不能自动重开。
2. **读取失败清目录（R0 优先）**：`server/src/tdx/catalog.ts` 把 readdir 失败当作空数组，再删除未扫描到的股票；需保留上次成功版本并报错。
3. **版本一致性（R0/R1）**：日线外部文件、目录元数据及权息更新没有统一版本发布；历史修订可能与已存账户/流水不同步。需稳定读取、修订检测和旧版保护，推进前确认权息就绪。
4. **旧训练规则漂移（M5 前置）**：费用及 T+1 每次交易读取全局 settings，先建立训练规则快照再开放设置页。
5. **不复权账户权息（M5 前置核查）**：当前 advanceTraining 仅在 forward 路径调用 applyPositionEvents，不能直接把显示复权默认值开放成影响真实持仓权益的选项。
6. **M4 统计口径**：部分平仓、未清仓、零交易/零亏损、手续费/权息、基准缺失、结算幂等和稳定排序尚需用样例固化；历史数据不足结束的成绩不能直接归入完整周期。
7. **保留的体验待办**：锚点标签 08:00 后缀、数据尾后空白滚动，进入 M5 评估；已有 cursor-only hover、休眠盲训、单右轴属于既有边界，不应继续混列为未修 Bug。

本轮只登记上述问题，没有声称已经修复。详见 [新功能开发计划](../日线更新与数据源适配-开发计划.md)。
