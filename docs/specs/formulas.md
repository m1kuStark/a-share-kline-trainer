# 公式指标

首批仅用于图表显示：主图叠加与独立副图，不联动选股扫描、条件单或账户操作。引擎与 API 实施依据见 [M9 产品化方案](../proposals/M9-04-formula-product-ui.md)及[只读接口](../engineering/formula-agent-api.md)。

## 启停与保存

用户于 2026-11-18 批准首批开发范围、顺序及内置示例处理；批准记录见 [ENG-PLAN-01](../verification/2026-11/ENG-PLAN-01/approval.md)。

- 设置「公式指标」中的「在图表启用」随创建、修改一同保存到本机公式库；重开设置、刷新页面仍保持。
- 内置示例新建时默认停用；用户可逐个开启。保存后关闭设置，进行中的图表自动显示该公式；停用后移除。升级及再次启动不重置用户已保存的选择。
- 预设位置：`MA_BULL_MAIN` 主图；`WEEK_MACD_SUB`、`QINIU_B1_SUB` 各自副图。自定义公式使用用户保存的位置。
- 内置名称与源码只读且不可删除。保存可编辑字段不夹带名称或源码，服务端继续拒绝对受保护字段的更新。
- 保存失败显示错误，清除之前的保存成功提示；失败操作不被当成成功保存。

## 求值和权限

训练求值继续使用截断至推进日、前复权、聚合后的行情；随机训练不泄露名称和代码。未来函数允许使用并明确标记。Agent 的 validate/evaluate 接口只读，不写训练、下单、画线或账户。

## 验收边界

源码验证、安装包运行和用户整批验收分别记录，见 [M9](../work-items/milestones/M9.md)。当前实现的回放使用当前公式库，未冻结录像时公式；公式副图高度不写入录像，公式副图画线回放回落主图。这些限制仍须整批呈用户验收，开发批准不代表用户接受，也不授权发布。
