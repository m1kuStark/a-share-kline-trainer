# 五档排行与成绩单入口

已结算训练的五档独立排行与成绩单入口（M4-01）。指标口径经拍板 S4 冻结（2026-09-29，按 roadmap §2.7 固定样例逐项确认），全部为持久事实的只读实时派生：不新增持久化指标表、不重算账户、不读训练日之后的行情。

## 排行接口与分组

- `GET /api/rankings?tier=<1M|3M|6M|1Y|2Y>`：非法/缺档位 400；存在 running 训练时 409 `HISTORY_ACTIVE_TRAINING`（与历史/成绩单同一守卫，异步基准读取后复守卫）；TDX 离线时除超额外照常可用。
- `GET /api/rankings?view=range`：仅返回 `tier='RANGE'` 且 `range_start`、`range_end` 完全相同的自定义区间组；起止日期不同的训练不会互相比较，也不会混入五档排行。
- `GET /api/rankings?view=industry[&industry=<id>]`：按明确版本化行业目录分组；未配置或目录不是 56 个有效行业时返回 `industry.status=unavailable`，不扫描本机目录猜测板块归属。
  未带 `industry` 时返回完整 56 个行业（允许空排行）供前端选择器展示；带行业 id 时只返回该行业，避免把所有板块成绩一次性铺开。
- `GET /api/rankings?view=stock&code=<六位代码>`：按股票代码精确分组，只比较该股票的已结算训练；没有成绩返回 `stock.status=empty`，非法代码返回 400。
- 只收五档 settled 训练：RANGE（自定义范围 preset/latest/bars）不入榜，放弃不入榜。行级不可认证（坏规则/legacy-raw/结算点缺失/权益点非有限）不入榜，并以 `excludedUnavailable` 如实计数。
- 分组：`complete`（到期结算）/`earlySettled`（提前结算）。
- 排序：完整组 收益率↓→最大回撤↑→胜率↓（null 殿后）→id↓（稳定键）；提前组 收益率↓→id↓。
- 行字段：id、代码/名称、分组、起止、实际天数（区间内持久权益点数＝实际经历的交易日，非自然日）、初始资金、最终权益、收益率、最大回撤、胜率、盈亏比、交易笔数、沪深300超额（行级 null 时附中文原因）、基准整体状态。

## 指标口径（冻结）

- 收益率/最终权益：与历史列表同一手算口径——只认结算日持久权益点，不从末笔现金/最新价重算。
- 最大回撤：持久权益点峰值 `max((peak−equity)/peak)`，不插值；0/1 个点＝0（无下跌观察的真实推导）。
- 胜率/盈亏比（摊薄成本法）：每笔卖出＝1笔平仓（买入建仓/加仓不计笔）；单笔已实现盈亏＝卖出净入金(金额−卖出费)−所卖份额摊薄成本（成本含买入费与配股缴款，按卖出比例摊销，与账户 `applyTrade` 同源）。胜率＝盈利卖出笔÷总卖出笔；盈亏比＝平均单笔盈利÷平均单笔亏损（亏损取绝对值）。零卖出→两者 null；零亏损或零盈利→盈亏比 null（"--"，无限大不虚构为数值）。pnl=0 不计赢也不计亏（胜率分母含、盈亏比两侧不含）。持有期分红不进单笔（已入权益，不与权益口径双计）。
- 沪深300超额：基准＝通达信 `vipdoc/sh/lday/sh000300.day`（与 TDX 体检同源）；向后对齐（起点=≤startDate 最近收盘、终点=≤settleDate 最近收盘）；超额＝训练收益率−基准区间收益率（算术差）。基准文件缺失/无 TDX→整组 null＋原因；训练起点早于基准覆盖→行级 null＋原因。数据不足不冒充。
- 幂等：settle/advance 对非 running 一律 409；指标实时派生、无回填，重复查询结果一致。

## 复盘展示状态

- 成绩单页内展开：`GET /api/trainings/:id/bars` 只读取K线（止于结算日，推进日截断口径），展示 B/S 成交标记、当日保存画线叠加与持久权益曲线。
- 当前版本暂时不在成绩单中展示 K 线复盘入口、K 线图或画线叠加；历史画线和 `/api/trainings/:id/bars` 接口保留，待新的复盘方案确认后恢复展示。
- 防未来守卫仍保留在 bars 接口：存在 running 训练时只放行该局自身，其余训练返回 409 `HISTORY_ACTIVE_TRAINING`。

## 行业目录与历史稳定性

- 行业目录优先使用 `TRAINER_INDUSTRY_MAP` 显式指定 JSON 文件；未指定时读取已确认的通达信 `T0002/hq_cache/tdxzs3.cfg`（`type=2` 行业目录）和 `tdxhy.cfg`（股票归属），只接受恰好 56 个唯一行业，并以两文件内容哈希作为版本。文件缺失、格式错误或不是 56 个行业时整个行业视图不可用，不猜测归属。
- 证券名称读取顺序为 TNF → `base.dbf` → 通达信 `pttab.dat`（停牌/退市代码兜底）；找不到名称时才显示代码，不能因单个 TNF 缺行而把名称缓存永久降级为代码。
- 训练记录保留 `industry_id`、`industry_name` 和目录哈希列。旧记录没有快照时显示“未分类”；发布前应使用创建时快照填充，不能把当前目录变化静默解释为历史归属。

## 明确不做

排行指标持久化缓存或回填；复盘画线编辑；训练时钟、成交理由、条件单（V4 范围）。
