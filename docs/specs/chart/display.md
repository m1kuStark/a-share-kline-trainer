# 图表与工具

## CHART-DISPLAY / CHART-VIEWPORT

- 日/周/月观察周期，推进粒度恒为日；MA25/60/144＋VOL＋MACD 已在 V1。
- 初始最多载入 **1040 根（840＋200 根均线暖机）**；实际同屏上限 **840 根**，缩放 1～840，默认约 150。向左动态加载更早历史，840 不是总加载量。
- ↑ 放大、↓ 缩小，以视图右端为锚；←/→ 移动十字光标；Home 恢复默认视图；空格推进，B/S 买卖。
- `]` 日→周→月→日，`[` 反向。输入框、编辑弹层、自定义模式和未完成绘图按交互守卫隔离快捷键。
- 默认模式主副图空白区右向框选放大、左向框选缩小；多选模式框选只选画线。价格轴和副图分隔条不参与框选。
- 滚轮平移历史，价格轴滚轮缩放纵轴；程序化缩放前恢复纵轴自动适配。
- VOL/MACD 双击最大化、再双击恢复。分隔条原生 7px 命中带优先于框选、画线和多选，尺寸拖拽不得改变柱宽。
- 红涨绿跌、阳线空心/阴线实心；MACD 白 DIF、黄 DEA、实心红绿柱。深色主图、VOL、MACD、成交标记带均为纯黑，控件使用中性灰。
- 当前阶段价在开盘和收盘均使用同一种最新价虚线，价格只标在右侧价格轴，绘图区内不重复写价。存在有效阶段价时只显示这一条活动价位线；红/绿/灰按当前阶段价相对实际前一交易日收盘价判断，不按周/月聚合 K 线推断。开盘只显示已知开盘价，不注入当日完整 OHLC；最新视窗的自动纵轴范围须容纳跳空开盘价，历史视窗与手动纵轴缩放沿用原有规则。
- B/S 成交标记（B 橙、S 蓝，密集聚合防重叠）悬停/聚焦预览、点击打开只读详情浮层：单笔直显、聚合先列笔次再选具体成交，可固定；固定后移开、切周期、resize 仍显示当前仍存在的成交，Esc/关闭/解除固定恢复普通收起。详情只含日期（双盲时全部文本与 aria 只用相对日期）、买卖、序号、原始成交价、股数、金额、费用，严格按笔显示不合并；chartPrice 不冒充成交价。浮层内 Space/B/S/Delete/方向被隔离，不触发交易、推进或画线；理由/阶段/订单字段待 TRAIN-03，浮层不发起任何写请求。
- 顶部紧凑，次要详情用浮层。当前推进日、实际可见末日及来源数据末日须分清；日期轴抽样刻度不作为数据截止依据。
