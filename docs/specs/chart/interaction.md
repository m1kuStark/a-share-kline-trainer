# 画线、交互与保存

## CHART-DRAWING 与 CHART-PERSISTENCE

现有 **23 种**：线段、射线、直线、水平直线/线段/射线、垂直直线/线段/射线、平行直线、价格通道线、斐波那契线、画笔、价位线、矩形、圆圈、圆弧、箭头线、看涨箭头、看跌箭头、百分比线、诅咒线、文本。

- 默认黄色、1px 虚线；多选为黄芯白圈锚点并保留线体颜色。价格文字透明无填充并随对象颜色，百分比/斐波那契同时显示比例与价位。
- 诅咒线按高点→低点取点，仅保留两点均价的 50% 水平射线，从第二点时间向右延伸。
- 颜色、粗细、线型、端点价格编辑；主副图绘制、吸附、移动、多选、撤销/重做/清空均已实现。
- 文本锚定图表坐标；常用工具在自定义模式拖入、移出和排序，其余工具可折叠。保存状态固定占位，不挤动工具和账户。
- 按训练保存用户对象，存 timestamp/value 及语义窗格；引擎标记不进入画线历史。256 KiB、500 对象、单对象 256 锚点上限。
- 多空反转开启时画线显示坐标跟随镜像（p′=2P₀−p），持久存储值恒真实价：既有画线不改写、镜像态新建画线回存真实价，关闭开关后画线位置不变（2026-10-26 拍板，详见[显示规范](display.md) CHART-INVERT 节）。
- 画线按周期隔离（用户 2026-10-19 拍板：画线不跨周期可见，维持现状）：每条画线盖印所属周期（日K/周K/月K），仅在其所属周期视图显示；切到其他周期不可见＝过滤显示而非删除（服务端保存集与他周期画线不动），切回原周期恢复显示。任何周期视图下的增删保存都与其他周期集合合并后整包提交，不覆盖他周期存量；存量无周期盖印的旧画线按日K 对待。
- 保存失败保留本地副本；首次读取失败不得以空数组覆盖服务器。原始 D 单元见 [M3 计划](../../archive/2026-09/M3-画线工具链-开发计划.md)。

## 编辑和边界细则

CHART-MEASURE-02（用户 2026-11-08 拍板）：Shift+左键**两次点击 K 线**建立区间测量——第一次点击设定起始 K 线（虚线竖线提示），第二次点击设定结束 K 线，显示半透明 Select Box 与数据窗口。窗口含：起点/终点日期与收盘价、涨跌幅、价差、K 线数量（含首尾），以及区间涨跌幅、最高/最低价（日期）、振幅、总成交量/额、上涨/下跌/平盘根数；区间统计口径同右键区间统计（首根前收为基准，缺前收用首根开盘）。Select Box 左右边界可拖动调整起止 K 线，数据窗口实时更新。Esc/普通点击/滚轮/失焦/周期或视窗变化清除；绘图取点、多选、Ctrl/Alt/Meta 组合、价格轴/时间轴、分隔条优先；测量激活期间交易/推进/删除热键被吞。多空反转开启时仍以真实 loadedData 计算（起止收盘为真实价，决策信息不撒谎）。回放只读可用；不写训练、画线或录像。

主图空白右键拖选松开后提供区间统计菜单；普通右键菜单可进入左键选区，正反向、单根都包含首尾。绘图取点、用户图形右键编辑、多选、分隔调整及轴缩放优先；副图与轴区不启动统计。选区临时着色，菜单和统计弹窗可见，Esc/切周期/数据替换取消，窗口隔离推进/交易/删除热键；统计不改视窗、画线、撤销史或录像。回放仍只读，允许统计。多空反转开启时统计仍按真实价：数据源固定为组件真实序列 loadedData，不读库内镜像序列（2026-11-07 维护者拍板）。

端点价格两位小数，粗细1～5px，不编辑横坐标，多选按选项卡批量编辑。文本支持多行/粗斜/字号，图表坐标锚定，不做绝对定位；靠边换行避让，极长缩小后省略显示但保留完整文本。水平射线沿第二点方向，圆按直径两端定正圆，折线右键结束/Esc取消。hover只改cursor。

引擎标记不可选中或持久化；主图手势和弹层不得越出训练主界面。常用自定义期间禁交易热键和绘图；保存状态固定不挤布局；清仓成功立即清成本线，即使后续行情GET失败。绘图默认dash[4,4]同源。完整事件裁决见[交互实现](../../../web/src/components/docs/interaction.md)，库钉定见[适配登记](../../../web/src/components/docs/library-adapter.md)。


CHART-GESTURE-PRIORITY：事件优先级统一裁决，原生7px分隔条最高优先，多选框选不缩放，主副图同权。范围和快捷键见[显示规范](display.md)。

CHART-ZOOM-01（用户 2026-11-07 拍板）：Ctrl+滚轮缩放与 Shift+←/→ 键盘平移走既有 wheel/keydown 入口，与框选、测量、多选、绘图取点互斥关系不变；价格轴滚轮仍只做纵轴缩放，不进入平移或框选。

CHART-PAN-01（用户 2026-11-07 拍板）：底部时间轴上的普通左键拖动平移在 pointerdown capture 最先裁决并独占该次手势（x_axis_pane 不参与框选/测量/多选/分隔条）；图表区左键框选、Shift 测量、Ctrl 多选与价格轴缩放优先级不变；只读回放沿用同一平移路径。

成交标记详情提供“买卖数据/笔记”两个页签。笔记页首次打开会临时固定浮层，保存后解除固定并恢复悬停收起；笔记按 `training_id + trade_seq` 写入本机 SQLite 的 `trade_notes`，文本上限 4000 字，深浅主题共用界面变量。

CHART-MEASURE-03（用户 2026-11-09 验收反馈）：两点区间测量/区间统计的统计源固定为**当前周期库内 K 线**（不得用日线序列套周/月索引）；Select Box 左右边界落在起止 K 线中心（与十字线竖线一致），拖动边界实时更新。多空反转下按真实价统计并保持 high/low 语义。

CHART-MEASURE-04（用户 2026-11-10 Issue #8 请求「类似 MT5 的测量工具」）：训练页顶栏在「划线」旁新增「测量」toggle 入口（aria-pressed、中文名称与 title、尺子类图标；1024×680 下顶栏不溢出，窄档压缩为图标入口但保留可访问名称）。进入后光标为十字、图上提示「测量模式：拖动或两次点击选择起止K线，Esc 退出」、按钮高亮。建立方式两条并存：①主图按住左键从起点 K 线拖到终点 K 线松开——拖动期间只增长 Select Box 预览、松手才出数据窗口；②两次左键单击（第一次起点＝虚线竖线锚点提示，复用 measurementAnchor 视觉，第二次终点）。起止索引按时间排序归一（反向拖动/反向点击得到同一区间），建立过程与结果完全复用 CHART-MEASURE-02/03 的 RangeMeasurement 数据窗口、Select Box 与可拖边界（字段、当前周期统计源、镜像真实价口径不变）；模式内可继续拖动边界调整，再次拖动/点击即建立新测量并替换旧值，模式保持激活。退出并清除：再次点「测量」、Esc（一步退出）、切周期、结束训练、离开训练页、进入画线工具或多选模式；仅清除当前测量而保留模式：滚轮/缩放/平移、窗口失焦、窗口 resize、可见范围变化、副图指标开关切换（沿用既有 closeMeasurement 路径并显式取消进行中的拖动预览，不留陈旧 Select Box/窗口）。拖动建立期间窗口失焦或窗外松键（pointermove 检测到 buttons=0）即取消预览与手势，不产生半成品测量。仲裁沿用 CHART-GESTURE-PRIORITY：分隔条、价格轴、时间轴拖动平移（CHART-PAN-01）、绘图取点、多选、Ctrl/Alt/Meta 组合优先；测量模式内主图空白左拖不再触发框选缩放而改为建立测量。训练热键（推进/买入/卖出/删除画线）在测量模式内被吞：判定走 Training 键盘入口的**应用可配置键位**（keyboardShortcuts 的 advance/buy/sell/deleteDrawing，与画线模式同一入口），输入框聚焦与中文输入法组合（isTyping/isComposing）不吞键；已建立测量后沿用既有「测量激活期间全吞」保护。MA 设置原生模态打开时由模态接管 Esc（先于测量模式判定）。模式内点击已有画线也按测量优先（不启动画线选中/拖动）。纯展示层：不写训练/画线/撤销史/录像（drawings 不变、无写请求、不重载行情、不改视窗）；回放页本轮不加顶栏入口，既有 Shift 两点测量在只读回放可用且新模式代码零写请求；多空反转开启时按真实价计算与显示。
