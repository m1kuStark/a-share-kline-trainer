# 画线、交互与保存

## CHART-DRAWING 与 CHART-PERSISTENCE

现有 **23 种**：线段、射线、直线、水平直线/线段/射线、垂直直线/线段/射线、平行直线、价格通道线、斐波那契线、画笔、价位线、矩形、圆圈、圆弧、箭头线、看涨箭头、看跌箭头、百分比线、诅咒线、文本。

- 默认黄色、1px 虚线；多选为黄芯白圈锚点并保留线体颜色。价格文字透明无填充并随对象颜色，百分比/斐波那契同时显示比例与价位。
- 诅咒线按高点→低点取点，仅保留两点均价的 50% 水平射线，从第二点时间向右延伸。
- 颜色、粗细、线型、端点价格编辑；主副图绘制、吸附、移动、多选、撤销/重做/清空均已实现。
- 文本锚定图表坐标；常用工具在自定义模式拖入、移出和排序，其余工具可折叠。保存状态固定占位，不挤动工具和账户。
- 按训练保存用户对象，存 timestamp/value 及语义窗格；引擎标记不进入画线历史。256 KiB、500 对象、单对象 256 锚点上限。
- 多空反转开启时画线显示坐标跟随镜像（p′=2P₀−p），持久存储值恒真实价：既有画线不改写、镜像态新建画线回存真实价，关闭开关后画线位置不变（2026-10-26 拍板，详见[显示规范](display.md) CHART-INVERT 节）。
- 画线按周期隔离（用户 2026-10-19 拍板：画线不跨周期可见，维持现状）：每条画线盖印所属周期（日K/周K/月K），仅在其所属周期视图显示；切到其他周期不可见＝过滤显示而非删除（服务端保存集与他周期画线不动），切回原周期恢复显示。任何周期视图下的增删保存都与其他周期集合合并后整包提交，不覆盖他周期存量；存量无周期盖印的旧画线按日K 对待。
- 保存失败保留本地副本；首次读取失败不得以空数组覆盖服务器。原始 D 单元见 [M3 计划](../../archive/2026-09/M3-画线工具链-开发计划.md)。

## 编辑和边界细则

Shift+左键在主图拖动为两点快捷测量，实时显示并在松开后保留；Esc、再次点击、失焦、数据/视窗/尺寸变化清除。沿现有pointerdown/move/up/cancel及keydown入口仲裁，无独立监听状态机；绘图取点、多选、Ctrl/Alt/Meta组合、轴区和分隔优先，普通模式的显式Shift可从已完成画线上起测而不抓取图形。拖动期间隔离交易/推进/删除快捷键，中途松Shift不改变本次手势归属；右键区间统计及普通框选/缩放不变。多空反转开启时测量仍按真实价：像素→显示域价位先按活动 P₀ 反镜像回真实域，五项字段与图上直观价位可能不同（决策信息不撒谎，2026-11-07 维护者拍板）。

主图空白右键拖选松开后提供区间统计菜单；普通右键菜单可进入左键选区，正反向、单根都包含首尾。绘图取点、用户图形右键编辑、多选、分隔调整及轴缩放优先；副图与轴区不启动统计。选区临时着色，菜单和统计弹窗可见，Esc/切周期/数据替换取消，窗口隔离推进/交易/删除热键；统计不改视窗、画线、撤销史或录像。回放仍只读，允许统计。多空反转开启时统计仍按真实价：数据源固定为组件真实序列 loadedData，不读库内镜像序列（2026-11-07 维护者拍板）。

端点价格两位小数，粗细1～5px，不编辑横坐标，多选按选项卡批量编辑。文本支持多行/粗斜/字号，图表坐标锚定，不做绝对定位；靠边换行避让，极长缩小后省略显示但保留完整文本。水平射线沿第二点方向，圆按直径两端定正圆，折线右键结束/Esc取消。hover只改cursor。

引擎标记不可选中或持久化；主图手势和弹层不得越出训练主界面。常用自定义期间禁交易热键和绘图；保存状态固定不挤布局；清仓成功立即清成本线，即使后续行情GET失败。绘图默认dash[4,4]同源。完整事件裁决见[交互实现](../../../web/src/components/docs/interaction.md)，库钉定见[适配登记](../../../web/src/components/docs/library-adapter.md)。


CHART-GESTURE-PRIORITY：事件优先级统一裁决，原生7px分隔条最高优先，多选框选不缩放，主副图同权。范围和快捷键见[显示规范](display.md)。

成交标记详情提供“买卖数据/笔记”两个页签。笔记页首次打开会临时固定浮层，保存后解除固定并恢复悬停收起；笔记按 `training_id + trade_seq` 写入本机 SQLite 的 `trade_notes`，文本上限 4000 字，深浅主题共用界面变量。
