# 操作录制、复盘与分享

状态：首批实施中；工程完成与验收证据以[REC-01任务](../work-items/tasks/REC-01.md)为准。

## RECORDING-DEFAULT

录制默认开启。开始训练前的首页提供开关，训练过程中也可手动关闭/恢复；训练界面右侧操作区持续显示“正在记录”或“已暂停记录”，鼓励保留记录但尊重关闭操作。录制失败、磁盘/浏览器空间不足不能继续假显示成功。每场新训练恢复默认开启，同一标签页刷新本场训练保留暂停状态；首批不自动删除历史录制。

## RECORDING-PURPOSE

记录用于自动测试、bug复现、个人复盘和用户间分享，是正式用户功能。覆盖买卖及拒单、推进、日/周/月查看、绘图创建/拖动/编辑/删除、撤销重做、视窗及重要界面状态；记录版本、所用数据、实际结果和操作顺序。

暂停/恢复本身保留元事件；暂停期间标记未记录区间，恢复时保存新的完整状态检查点，不能伪造遗漏操作或宣称连续完整。

分享由用户主动导出，不自动上传。接收者使用K线训练器即可导入查看；分享包携带所需行情/权息、规则、初始状态及操作，不依赖发送方本地路径。未完成训练的分享只带已可见区间，回放逐步截断；版本/数据不兼容时明确提示或只读展示，不能静默产生不同结果。

## 验收边界

复盘展示还原当时记录；业务重放重新执行并比对数值；真实UI重放用实际鼠标键盘验证完整交互。三者分别报告，不能以写内部状态代替真人流程。精确重放依赖数据/规则冻结；现有缺口见[DATA-03](../work-items/tasks/DATA-03.md)、[TRAIN-01](../work-items/tasks/TRAIN-01.md)。

使用schemaVersion=2紧凑记录：语义事件、不可变行情/图形版本、实际账户结果和轻量检查点；默认导出`.trainer-session.json.gz`，也可导出可读JSON。旧v1 JSON/浏览器记录按需迁移，原存储保留。回放只读并按步骤取当时版本，不重复成交。

导入压缩体积25MiB、v2解压JSON128MiB、旧v1迁移256MiB；事件50000、轻量检查点20000，资源预算与取消规则见v2合同。无效文件拒绝且不改变现有训练；这些是导入保护，不是自动停录。两年正常训练必须支持完整记录/导出。规则只描述实际观察值，不伪称创建时规则冻结。

录制准备阶段阻止操作，失败明确提示后允许继续训练并提供重试。复制标签页若已有录制写者，本页建立独立录制；原场不被覆盖。暂停恢复与未记录区间持续显示，失败期间不声称遗漏操作已被记录。

现行格式见[v2接口](../engineering/recording-v2-contract.md)，旧格式见[v1兼容合同](../engineering/recording-contract.md)，设计理由见[紧凑方案](../proposals/session-recorder/compact-storage.md)。后续确定性业务重算仍受DATA-03/TRAIN-01约束。
