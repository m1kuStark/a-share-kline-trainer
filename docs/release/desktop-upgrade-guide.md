# 桌面版安装与升级指引（用户向）

> 适用：想把 K线训练器升级为 Windows 桌面应用（exe 安装版）的用户，尤其是现在正在用 zip 解压版的老用户。
> 你的历史训练数据**不会丢、不用搬家**——先讲结论，再讲怎么做。

## 一、从 zip 版升级到桌面安装版（三步）

1. **下载安装器**：到本仓库 GitHub 的 Releases 页，下载最新版的 `kline-trainer-desktop-setup-v<版本>-windows-x64.exe`。
2. **双击安装**：传统安装向导——选安装位置（默认装到你自己的用户目录，不需要管理员权限）→下一步完成。安装完桌面和开始菜单会有「K线训练器」快捷方式。
3. **首次打开**：启动后如果检测到你以前 zip 版留下的训练数据，会弹一次提示「已沿用历史训练数据」——确认即可，历史训练记录原样出现在「历史训练」里。

> 这个「沿用」是就地采用（adopt-in-place）：桌面版**直接打开你原有的训练库文件，不复制、不搬家、不删除**。你原来的数据一个字节都不会被改动。

## 二、我的数据在哪里？怎么备份？

| 形态 | 数据位置 |
|---|---|
| 桌面安装版/便携版（首次启动且发现历史数据） | 沿用原位置（见启动时的提示弹窗，会写明绝对路径） |
| zip 解压版 | 解压目录下的 `data\` 文件夹（训练库＝`data\trainer.sqlite`） |
| 全新机器无历史数据 | `C:\Users\<你>\.a-share-kline-trainer\`（训练库＝其中 `trainer.sqlite`） |

**备份方法**：退出训练器后，把上述位置整个文件夹复制到别处即可（`trainer.sqlite` 是单文件库，复制即备份；恢复＝拷回去）。升级/换机前建议先做一次。

## 三、老 zip 版还能继续用吗？

可以，两者可以并存，但有一条**重要注意事项**：

- **不要同时运行两个**。同一份数据目录同时被 zip 版和桌面版打开，启动时桌面版会检测到占用并询问你（复用/重启/退出三选一）——按需选择即可；最稳妥的做法永远是**用一个时关掉另一个**。
- zip 版的「在线更新」功能照旧可用（它更新 zip 形态自己）；桌面版的「在线更新」更新桌面安装版自己。两条更新道各自独立。
- 想彻底切换到桌面版：确认桌面版能正常看到全部历史训练后，zip 目录留作备份即可，不需要删除。

## 四、桌面版怎么更新？

设置面板 →「关于与更新」→「检查更新」。有新版时会显示版本说明，确认后自动下载并在**安全退出当前训练**后安装重启（未完成的训练会保存在历史里，不会丢）。

- 安装版：应用内直接完成升级。
- 便携版（`kline-trainer-desktop-v<版本>-windows-x64.exe`）：检查到新版后请按引导下载安装器升级为安装版（便携版自身不做原地更新）。

## 五、装了不想要了？

从系统「设置→应用」或开始菜单的「Uninstall K线训练器」卸载。卸载只删除程序本体；**你的训练数据目录不会被删除**（数据目录位置见 §二，不需要时可自行删除）。
