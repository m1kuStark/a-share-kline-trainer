这是 2026-10-20 本地候选，版本沿用 **1.3.0**；请用候选编号和 SHA256 区分旧包。没有公开发布。

## 怎么打开

完整解压 `Kline-Trainer-BUILDER-ACCEPT-01-20261020.zip`，进入 `BUILDER-ACCEPT-01-20261020` 文件夹，双击 **Start-Acceptance.cmd**。已解压目录可直接启动。不要直接运行 `app/` 内 exe，它没有验收数据隔离参数。

此包无需安装，训练、设置、录像和缓存只写本目录的 `.acceptance-data/`。随包提供冻结的行情样本，可立即试用；样本截至 2026-09-16，不代表最新行情。训练前出现数据更新提示时，本次验收选“仍要开始训练”。

## 建议用 5 分钟检查

1. 输入 `600519`，点选贵州茅台，选“3个月”，将起始日设为 `2026-09-01`，保留“记录操作”勾选，开始训练。窗口应直接显示，无需浏览器或开发环境。
2. 买入一次、推进下一日、卖出；画一条线，再切换日/周周期，查看账户、画线和日期是否符合预期。
3. 提前结算，打开历史成绩单。切换深浅主题，缩小窗口，查看收益曲线与七列成交明细；可滚动到费用列，关闭按钮可达。
4. 打开训练录像并回放刚才的操作。它应显示你的交易和图表状态。
5. 点击“保存并退出训练器”，看到“训练器已退出”后关闭窗口，再用 **同一个启动脚本** 打开。刚才的历史和录像应仍在。

若要搬走这次验收数据，请关闭程序后保留整个验收目录，尤其是 `.acceptance-data/`；只复制 SQLite 不包含浏览器中的录像。
