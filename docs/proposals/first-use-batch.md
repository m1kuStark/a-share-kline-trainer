## 训练范围规则

以下为本轮设计口径，实施时同步训练规格、API、录制格式与回归，不能只改表单。

| 模式 | 起止和长度 |
|---|---|
| 月/年预设 | 初次打开及用户点击周期时，用上海时区的系统日期减去1/3/6/12/24个自然月填入起始日，默认终点固定为该系统日期。月末按目标月最后一天裁切；例如9月22日选择3个月得到6月22日至9月22日。用户手改起始日后按该日期加所选周期；普通重绘、选股、数据刷新不覆盖手填值。再次点周期视为重新生成默认区间。 |
| 到最新日线 | 用户指定起始日，终点取创建时该股票已验证、可用的最新完整日线日期，并保存该终点；之后数据更新不会延长本轮训练。页面显示实际截止日，不能称为“到今天”或全市场最新。 |
| 自定义日K根数 | 输入正安全整数N，自指定起始日开始取该股票N根有效日线。包含首根训练K线，不含起始日前的历史观察区；N=1也有明确结束行为。周/月显示不改变日K计数。 |

界面显示请求区间、实际首末日、日K根数及调整原因。新模式起始日落在周末/休市日时，取区间内首根有效日K，终点取区间内最后一根已确认日K；不可将前一交易日偷偷算进所选区间。保留原请求日期，不因对齐交易日再次平移计划结束日；老训练和旧录像保留旧含义。

服务端是最终校验者，预览只返回日期、数量和原因，不返回未来OHLC、收益或交易结果。创建须复核与预览一致；两次读取期间行情变化须刷新预览并明确提示，不能用过期结果创建。

- 最早本地日线不等于真实上市日；没有可靠上市信息时提示“本地历史始于……”。上市较晚、历史缺失、尾部未下载分别诊断。
- 固定周期超出当前可证明范围、自定义N超过可用根数、起点晚于可用尾日、区间无K线时阻止创建，并显示需要/已有范围或数量。提供重新选日期、缩短周期或先去通达信补日线的操作；不静默截短并当作完整训练。
- 到最新模式只承诺当前所选数据范围；尾部落后时展示截止日及新鲜度提醒。停牌、节假日和数据缺口无证据时标“覆盖待确认”，不用全市场尾日替代个股覆盖证明；尊重DATA-02已有保守结算规则。
- 未来日期、非法日期、N为空/0/负数/小数/非有限值均前后端校验。自定义范围不凭空套用两年容量上限；以实际可用数据为界，并测量较长范围的预览、录制和回放成本。
- 新模式不得冒充既有五档排行。旧请求、已运行/已结算训练及v1/v2录像继续兼容；新字段采用明确版本契约，旧阅读器对不支持的格式给出可理解提示，不伪装成3M。

## 并行调度与共享文件

沿用[模型协作协议](../engineering/model-delegation.md)：GLM5.3Flash、最高思考档、已验证1M配置，最多三路独立worktree、Prompt、日志与看板。当前仅登记计划，未派发后台开发任务。

先由集成人冻结三份最小合同：新鲜度结果；安装候选/诊断/保存生效；训练范围预览/创建及录制兼容。具体接口类型与工作树基础SHA写入各次派发Prompt后才能开工。

第一批可独立并行：DATA-05纯日期/状态计算；SETUP-01只读发现/诊断模块；TRAIN-02纯日期/根数范围规划器。第二批再分原生接入桥、训练服务端兼容、向导/创建界面。一个任务写完且合入后，下一任务才能接管同一文件。

`server/src/api.ts`、`server/src/db.ts`、`web/src/api.ts`、`web/src/App.vue`、启动器主文件、共享类型、迁移和全局文档由集成人单写。UI-02是小改动，由集成人在App接线时完成，不另派一个并写App的worker。TRAIN-02录制兼容可单独评审，但须等范围合同固定；不能顺带改交易、费用或画线规则。

每个worker Prompt须包含：任务卡和局部AGENTS、基线SHA、独立分支/工作树、独占文件清单、输入输出合同、失败回归及验收命令、禁写通达信/个人库/共享文件、提交与证据格式。遇Mimosa拦截保留原报告一次性交接，不绕过；从实际worktree根启动会话。
