# 两点价格尺与区间统计并存（#41）

2026-11-24 维护者决定：两项功能不冲突，**必须保留区间统计**。这一条是现行约束。下面关于新价格尺的入口、吸附显示等是设计提案，尚未上线，也没有据此改变已验收的手势。

| 用户要回答的问题 | 入口 | 结果与边界 |
|---|---|---|
| 这几根 K 线经历了什么？（现有） | 主图空白右键拖选 → 区间统计；或右键菜单进入选区 | 首尾 K 线均计入，保留最高/最低、成交量/额、振幅、上涨/下跌/平盘根数及原有统计窗口。周/月按当前周期；双盲隐藏日期。 |
| 两根 K 线的收盘和中间区间如何？（现有） | Shift + 左键依次点两根 K 线 | 保留虚线起点、Select Box、可拖边界和数据窗；按真实收盘/区间算，不把鼠标纵坐标当成交价。 |
| 起点 A 到终点 B 这两个**价位**相差多少？（新提案） | 建议在划线工具面板加「两点价格尺」，选中后普通左键取 A、B。未选中时不抢普通左键；不恢复重复的顶栏区间按钮。 | 两点可在主图空白处、同一根 K 线上，也可从右向左取。显示 A、B、差值 `B−A`、变动百分比 `(B−A)/A`；按取点顺序算，不能按日期排序后改符号。**不计算成交量/额、区间高低或给出交易建议。** |

### 边界与拟议交互

- 原右键菜单、右键拖选、Shift 两击均保留。建议在价格尺待取点期间若启动已有区间入口，先取消未完成的尺，再把该手势交还给原功能；不让一个手势产生两份结果。既有库图形编辑、多选、主副图分隔条、坐标轴不改优先级。
- 自由模式按主图纵轴反算价格；开启吸附后只在附近可见 K 线 OHLC 候选中寻找端点，明确标出「开/高/低/收」及价格。小标记与可命中范围分开，不把所有圆点永久放大。像素距离相同、脱离阈值时的处理属于待验证设计。
- 建议仅做临时读数：Esc、换周期或退出训练/回放时清除；不写训练、画线历史、录像或数据库。只在主图上取价；不开盘日内未来信息。多空反转若不能可靠还原同一价格坐标系，须明确限制，不能把镜像坐标当真实价格。分母为零不显示无意义的百分比。
- 实施前使用同一段行情演示三种状态：区间统计、空白处自由两点、邻近 OHLC 吸附。实施时必须补真实浏览器交错用例：旧右键/Shift → 价格尺 → 旧统计；同根两价、反向、临近高/收、回放只读、双盲不泄露。原有 `e2e/chart-analysis.spec.ts` 断言不删不弱化。
