# 操作录像机与自动验收

状态：讨论方案，尚未实现。2026-09-18。目标是让Agent理解用户每一步、复现问题，并让训练器加载记录复盘；自动化应承担重复训练回归。

建议记录**语义操作、实际结果和必要的界面轨迹**。视频适合看现象，结构化记录适合回放和断言；可附截图/视频，核心文件仍为可读JSON。

## 应先约定的范围

“全部操作”应覆盖开始训练、交易、推进、切换周期、视窗、图形创建/编辑/拖动/删除、撤销/重做、文本确认/取消、主题和结束训练；拒单、未完成绘图、加载失败及操作被守卫阻止也要记录。跨操作系统的其他应用操作不在训练器记录范围。

不默认逐帧记录每次鼠标移动。普通操作保存最终语义；拖拽、吸附等问题可开启详细输入轨迹。这样文件可读、体积可控，回放也不依赖某台电脑的固定像素。

## 能减少哪些人工工作

用户报告问题时导出一次记录，Agent定位失败步并生成回归；提交前自动跑固定训练旅程和历史问题库，附结果差异及截图。用户主要评估新交互、视觉偏好及产品规则，无需每次重走整套训练。

现有Playwright已能真实点击、按键、绘图及交易。还需稳定的控件语义、图表坐标映射、可观察的加载/保存/忙碌状态和完成信号。Canvas无法仅靠DOM表达所有几何，保留只读坐标投影辅助；不得通过写内部状态冒充真人交互通过。
