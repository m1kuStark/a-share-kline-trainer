# 记录格式

推荐逻辑格式为 `trainer-session`、`schemaVersion: 1`。简短录制可用一个JSON；包含行情、图片和长轨迹时导出 `.ktr-session` ZIP，内含manifest、events、checkpoints、data及attachments，用户仍只拿一个文件。schema保持同一逻辑模型。

## 文件组成

| 字段 | 必须保存的内容 |
|---|---|
| schemaVersion/sessionId | 格式版本、唯一会话标识，供迁移与去重 |
| app | package版本、Git SHA、dirty标记/构建指纹、图表库版本、规则引擎版本；0.1.0本身不足以辨识当前构建 |
| environment | 时区、locale、viewport、DPR、主题、键盘映射、浏览器版本；操作计时用单调相对时间 |
| dataset | symbol/market、时间范围、单位、原始日线和权息的可读取快照引用及SHA256；只有哈希不能复现 |
| rules | 实际费用、最低佣金、T+1、整手、权息处理及成交口径，不只存设置名称 |
| initial | 推进日、计划结束、完整账户、T+1批次/当日买入、流水、画线、视窗、周期及工具偏好；允许中途开始录制 |
| events | 单调seq、opId、相对时间、来源、动作、参数、阶段与结果 |
| checkpoints | 关键步后完整状态/哈希，供跳转、比对和恢复 |
| attachments | 截图、可选视频/拖拽轨迹，只含文件内受限相对路径 |

## 事件纪律

开始时追加started，完成时追加finished，共用opId；拒绝/失败/取消也闭环。异步UI操作可并发开始，但需要记录完成顺序、关联请求、stateRevision，以及撤销针对的操作ID。会话突然中断时，未完成事件保留为interrupted，不能猜测结果。

买入成功后行情GET失败是两个结果：账本交易accepted，图表刷新failed。HTTP请求重试不是用户又点一次；服务端幂等键防止重复执行。与最终写库绑定的领域结果由服务端确认，前端不能仅凭按钮动画记成交成功。

画线用稳定objectId、工具名、语义paneId、timestamp/value锚点、样式与文本。创建/取消、移动前后、批量编辑、删除和undo/redo各有明确动作；不能只保存最新图形集合。输入可附按钮role/name或快捷键，拖拽附归一化轨迹及视窗/坐标映射。只存像素坐标无法跨尺寸回放。

界面滚动/缩放可合并连续运动，但保留手势开始/结束和最终视窗；调试模式另保留逐样本pointer轨迹、修饰键和目标窗格。录制器应批量追加本地IndexedDB/服务端日志，避免mousemove同步写大JSON；退出前flush加恢复游标，导出时检查是否存在未落盘尾段。

## 兼容与导入

默认开启已确认。加入recording.pause/resume及segmentId，恢复段带完整checkpoint；缺口不推测。分享元信息可包含标题/作者、说明和完整性标识；默认不带凭据或本机绝对路径。仅有本机数据引用的记录不能标为可分享复现。

区分文件schema版本、应用构建、规则和数据版本。支持的旧schema显式迁移，未知版本拒绝或只读；数据/规则缺失、哈希不符时明确降级或停止精确回放。

导入只接受白名单动作和有界数据：检查文件数/总大小/事件数、有限数值、单调序号、ID引用、路径穿越及重复ID；不执行文件内代码或任意网络地址。复放写入隔离训练/数据库，默认不覆盖个人库或重复发成交。

金额和股数采用明确精度及单位，避免JSON浮点文本差异成为假失败；状态摘要使用规范化序列化和稳定排序。共享时可以去除本机路径和自由文本；未来盲训的未揭示行情由服务端保管并按步骤截断，不能因为导出给Agent就提前泄露答案。
