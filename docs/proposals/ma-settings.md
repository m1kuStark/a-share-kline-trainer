# 主图均线参数设置设计

任务：[MA-01](../work-items/tasks/MA-01.md)。基础提交：`5f74db0ed3e46000f19754efb5ecf7ee7f3e4835`。用户要求参考通达信固定八条均线的参数面板，先不做“应用所有周期”。本文描述方案；实际实现和验证进度以任务卡为准。

## 产品范围

日、周、月共用一套 MA 配置，浏览器内跨训练、刷新保留。首次默认 25/60/144，颜色沿用橙、青蓝、紫。周期单位为当前图表的 K 线根数，日线按交易日、周线按周、月线按月。MA 为收盘价等权简单移动平均，窗口含当前已知 K 线；形成中的周月线只使用训练推进日已经可见的数据。

提供固定八行，每行一个周期输入框和颜色选择。周期 0 表示关闭该条，1～1000 的整数表示启用；禁止重复非零周期、负数、小数、空输入和超过上限的数值。允许全部为 0，此时不绘制主图 MA，但设置入口始终存在。颜色使用六位十六进制 RGB。

不在首版引入周期独立配置、多套命名收藏、EMA、涨跌箭头或单独总开关。均线全部关闭可通过八行均为 0 实现。

## 交互

主图提供常驻“MA 设置”入口，位于图表顶部右侧，不覆盖左侧均线数值图例。按钮有键盘焦点及提示，绘图取点期间禁用。打开后使用居中模态面板，标题“均线参数”，说明“日、周、月共用；0 表示关闭”。

固定八行依次显示“第 1 条”至“第 8 条”，列为周期（K 线根数）、颜色。预设按钮包括默认 25/60/144、常用 5/10/20/60、中长 20/60/120/250。选择预设只修改草稿。恢复默认也只修改草稿；应用前曲线不变化。

点击“应用”校验并保存整套配置后关闭面板；无效输入显示具体行和原因，保持草稿可修正。“取消”、Esc 放弃草稿。打开时聚焦第一个周期输入，Tab 保持在模态内，关闭后回到入口。面板期间屏蔽推进、买卖、周期切换和画线删除等快捷键，也不能对画布发起手势。

保存失败应明确提示并保持面板，不能声称已跨刷新保存。配置读入失败、版本不支持或结构损坏回到旧默认，避免启动崩溃。浅色和深色面板跟随应用主题，小高度桌面允许面板内部滚动。

## 图表与数据

沿用钉定的 klinecharts 10.0.3 内置 MA。过滤周期为 0 的行后，周期和颜色按同一顺序提供给指标。应用通过公开 `overrideIndicator` 更新已有指标，不重建图表、不改变可见范围、柱宽、画线、训练日期或副图。全关闭时隐藏 MA；重新启用时恢复已有指标。

历史不足 N 根时，该位置的 MA(N) 不产生数值，图例沿用库的缺失值显示。不能用不足 N 根的平均值冒充完整 MA，也不能为了预热访问未来行情。

根据用户于2026-10-07确认的加载策略，训练页面按已启用最大周期申请预热：`warmup=max(200, 最大周期-1)`，默认最多1040根，MA1000最多1839根。服务端新增可选 `warmup` 参数（0～999），不传仍保持旧1040根行为。修改成长周期时，通过既有历史接口补齐目标加载量的缺口，走图库forward前插，保留视窗与画线；已有足够数据、缩短周期或只改颜色不补载。失败提示可重试，数据版本变化后丢弃过期响应，只读录像不补读。只影响已加载量，同屏仍上限840；历史不足的位置暂不出长周期数值，不补造数据。初始和历史请求都沿用截断→复权→聚合链。

偏好键 `trainer_ma_settings` 保存版本 1 及八条 `{period,color}`。与现有 VOL/MACD/KDJ 偏好一致，首版录像回放按当前浏览器 MA 偏好显示；不声称还原录制时均线配置。录像没有足够历史时不补读服务器行情。精确录像参数还原需后续单独扩展录制格式与迁移。

## 实施路径

1. `web/src/maSettings.ts`：默认值、预设、校验、客户端持久化和响应式配置。
2. `web/src/components/MaSettingsDialog.vue`：草稿面板、校验反馈及键盘/焦点管理。
3. `KlineChart.vue`：常驻入口、模态隔离、指标原位更新；保留原有图例数值。
4. `web/src/api.ts` 和训练页：申请扩展预热；服务端 bars 接口及训练引擎验证并使用参数。
5. 更新现行显示规格、模块说明、适配登记及回归。

## 验收矩阵

| 场景 | 期望 |
|---|---|
| 老用户无配置 | 25/60/144 及原颜色 |
| 修改周期/颜色并应用 | 图例和曲线对应新配置，视窗与画线保留 |
| 预设、取消、Esc | 草稿不影响已应用配置 |
| 重复/空白/小数/超限 | 阻止保存，提示原因 |
| 全部 0，再启用 | 曲线消失/恢复，入口保留 |
| 刷新、切日周月 | 共用配置仍保留 |
| 1000 周期和历史不足 | 有足够历史时数值正确，否则缺失，不看未来 |
| 面板内 Space/B/S/Delete/方向键 | 不触发训练或画线操作 |
| 深浅主题及 1440×900、1280×720 | 无溢出、可聚焦、控件可见 |
| 旧录像回放 | 按当前偏好显示，不发起行情补读 |

单测验证偏好校验、坏数据回退、实际图库 MA 数值及接口预热边界；真实浏览器验证面板、持久化、周期切换、画线/视窗保留和主题。门禁按[测试协议](../engineering/testing.md)执行，工程自验与用户验收分别记录。
