# 首次接入与通达信发现

2026-09-22设计草案，尚未实现。用户反馈：朋友下载后需复制配置、改路径和文件名，甚至把JSON写成JISON。目标是让首次训练无需编辑文本文件。任务入口：[SETUP-01](../work-items/tasks/SETUP-01.md)。

## 建议体验

启动器先打开可用页面，再显示“连接你的通达信”。程序只读取行情文件，不控制交易或写通达信目录。

1. **找位置**：后台快速发现。仅一个可用候选时显示“已找到通达信”，列安装位置、股票数、行情末日和“使用这个数据”按钮；多个候选并列展示，让用户选择，不按首个目录默选。数据日期标明是来源末日，不冒充每只股票都最新。
2. **检查数据**：区分“未找到程序”“找到了但未下载日线”“缺少权息”“无读取权限”。相应显示“打开通达信并下载盘后日线”“重新检查”“换一个目录”。提示根据真实检查生成，不要求用户理解vipdoc或gbbq。
3. **开始训练**：选择通过后自动保存设置。主按钮为“开始第一场训练”，次要入口为“先看分享的录像”。无通达信时仍允许离线导入回放。

没有找到时提供“打开通达信后重新检测”和“选择通达信文件夹”。后者弹Windows原生目录选择框，取消不报错；误选上层目录或vipdoc时，只在附近有限范围识别根目录并让用户确认。用户无需复制行情文件，也无需知道路径转义和扩展名。

## 自动发现的顺序与边界

先用已保存选择和显式配置，再查运行中的通达信进程位置、桌面/开始菜单快捷方式、可用的安装记录，最后查常见目录。候选按规范化路径去重；靠目录内容验证，不能仅凭程序名认定可用。券商定制版、绿色版可能没有注册信息。

默认不递归遍历全部硬盘。快速发现失败后才由用户点“扩大搜索”，仅扫描固定本地磁盘的有限深度，显示进度、允许取消，不跟随目录联接、不请求管理员权限、不扫描网络盘。扫描只取必要路径和文件元信息，不读取账号或无关文档。错误、时限和可用性都必须如实呈现。

发现安装与判断可训练分开：即使暂无日线，也应能识别已安装的通达信并指引补数据。安装识别、可读日线、权息、名称和基准检查分别返回结果；基准缺失不能被包成“连接完全正常”。本轮不实现联网补行情。

## 工程改造

沿用Vue/Fastify/Node模块化单体，不引入Electron。将启动器和服务端重复的三路径探测收拢为共享、可测试的发现模块；源码运行和便携包用相同判定规则。

首次引导必须能在数据源缺失或配置失效时打开。新增独立的启动诊断路径，不依赖现有`/api/env`先成功刷新目录和权息；失效配置进入可修复页面，不在打开页面前直接退出。

浏览器普通文件选择不能可靠提供服务端可用的本机绝对目录。由受控本机桥调用固定原生目录选择脚本；只接收选择动作，不拼接用户命令。新增扫描/选择/保存能力仅服务本应用页面，校验Host、Origin、一次性令牌与并发请求，不沿用开放CORS作为权限保护。

用户选择原子保存在dataDir，升级不再搬配置。兼容既有`trainer.config.json`、`--config`和环境变量：显式来源优先级须写入合同；被显式覆盖时界面说明原因，不能显示“已保存生效”但实际仍用另一目录。完整保存并复验后切换；失败保留旧选择，取消不写入。

当前`AppConfig.tdxRoot`启动时固定，协调器也持有旧来源。不能只写JSON然后声称已连接。首版由启动器管理保存后的受控重启，保留端口、数据库与浏览器origin；具体交接协议先冻结。活动训练不切来源，不清训练、画线或录像。保留“重新连接数据”入口以处理目录移动。

## 引导动画

动画适合解释操作，不能替代配置。连接成功后用可跳过的三条气泡演示“空格下一日”“买入/卖出”“保存后回放”，高亮真实按钮，按需查看。不强制播放长视频，不用假进度，不遮挡错误；支持减少动态效果及“以后不再提示”。先完成接入闭环，再打磨动画。

## 分工和验收

建议优先于完整M4排行与M5设置页处理，具体开发仍以任务启动为准。首批三路GLM：发现/诊断纯模块；原生选择、持久化与重启桥；首次引导界面。集成人先冻结候选、检查结果、取消、保存生效、错误及版本字段，集中负责启动器/API接线；共享文件不并写。

验收使用临时目录、隔离端口和数据库：仅一个/多个安装、券商版、未下载日线、缺权息、不可读、中文空格路径、误选目录、取消及超时；旧配置兼容、重启后记住路径、升级保留选择、活动训练拒绝切源。真实浏览器跑完发现→确认→训练→退出→再启动，以及无TDX直接导入回放。不得用开发者电脑恰好命中固定目录代替首次用户验收。
