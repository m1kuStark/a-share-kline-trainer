# 0001 分层文档与事实单一归属

状态：accepted；日期：2026-09-17；[用户接受记录](../verification/2026-09/DOC-design-acceptance/record.json)。

原文档把现行规则、过程、测试数量与进度混放；重复状态漂移，行数不能限制超长段落。采用根入口→模块规则/索引→主题→按需证据；规则靠近职责边界，禁止每个目录机械复制AGENTS。

规格定义行为，模块文档描述实现，任务卡记录工作，验证记录保存事实；status为派生摘要。代码与受影响正文同步，集成人更新全局摘要；结构检查接入基线流程，人工仍负责准确性与验收判断。

代价是增加小型主题页和索引维护。以真实任务读取量、漏规则/断链接/状态漂移检验效果，不以文件数少为目标。源代码大重构、永久运行隔离不属于此决定，仍列后续任务。

执行：[文档更新](../engineering/documentation.md)、[读取](../engineering/reading.md)。[原设计](../archive/2026-09/documentation-proposal/README.md)只供追溯，不默认加载。
