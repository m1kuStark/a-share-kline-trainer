## 冻结边界（2026-10-06，架构师 provisional 简报）

- 三维度：`random_stock`（选定起止日期＋随机股票）、`random_time`（选定股票＋随机时间窗，`window_bars` 正整数缺省 250）、`random_both`（全随机，同样 `window_bars` 缺省 250）。
- 信息隐藏是 API 级真隐藏（网络面板可见即算泄漏）：隐藏股票→运行中会话一切 API 响应不含股票名称/代码（含错误消息、分页、指标、悬浮数据等一切出口）；隐藏时间→K 线/指标 timestamp 全部经会话级随机常量偏移变换（间距与缺口保留、真实起点不可见；暴力反推不在威胁模型）；结算后结算载荷、历史列表、成绩单返回真实股票与真实日期区间，运行中一律不返回；REC 落盘不做二次脱敏（复盘回放属事后揭晓，文档注明）。
- 随机股票池：本地数据中可用 K 线根数 ≥ 窗口需求（含指标预热 200 根）的全部股票；默认不排除 ST/北交所（proposed_default）；随机性 Math.random 级即可，RNG 必须可注入。
- 随机时间段起点约束：窗末不超可用数据末尾、窗首留足指标预热；无可行起点 422 RANDOM_WINDOW_NOT_FIT；股票池空 422 RANDOM_STOCK_UNIVERSE_EMPTY。
- 经典模式零影响：既有训练创建/查询 API 与响应结构不变。
- 复权、规则快照、T+1、条件单等既有训练语义全部沿用；训练引擎撮合/推进/结算语义不改，随机模式只改"选股/选窗方式＋隐藏策略"。
- 数据库只增列不重建（trainings.random_mode / random_time_offset_days），迁移沿 db.ts addColumnIfMissing 兼容路径。
- 禁改：web/**（M7-02 范围）、scripts/release/**、训练引擎撮合/条件单语义。
