## 冻结口径（用户 2026-11-16 默认方案；详见提案）

- 存储 SQLite `formulas` 表（兼容迁移，不重建既有表）；字段 name(唯一)/description/placement/source/enabled/builtin/created_at/updated_at。
- 只读 agent 接口 validate/evaluate；无写训练/下单接口；错误人话、业务校验失败用 200 ok:false，请求形状错误 400。
- evaluate 训练上下文必须先截断至推进日再复权聚合（复用 trainingBars）；无训练时按 code 读 TDX 日线最近 N 根并标注“不复权”。
- 引擎：web/src/formula-engine 为唯一来源；服务端构建期 bundle（scripts/build/formula-engine-bundle.mjs）加载，dev/test 允许回退直接 import 源码；不得复制引擎实现。
- 通达信文本导入：兼容多行注释 `{...}`、`//`、全角字符告警；单行粘贴版可直接解析；不做参数精灵/公式管理器导出格式的全字段解析（参数区按可选注释/PARAM 处理，本批仅保存源码）。
- 未来函数：扫描后随 FormulaView 返回 futureFunctions，不禁止保存/求值。

## 行为

- 迁移后全新/旧库均可启动；公式 CRUD 持久化，重启保留；删除不触训练数据。
- validate：合法公式 ok:true + 未来函数清单；语法错误返回行/列与中文原因；空源码 400。
- evaluate：合法公式返回与 bars 等长的输出线（NaN→null）与日期时间轴；运行时错误 ok:false 人话；训练中调用不改变训练/画线/录像状态。
- 导入：多行公式/单行粘贴版保存后名称唯一性校验 409。
