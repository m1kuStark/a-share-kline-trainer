## 背景（oracle）

用户原话（2026-10-09 验收反馈，两项）：

- RF2-02："在随机时间模式下，K 线主图下方的横坐标时间轴上，仍然会看到日期信息。虽然这个日期信息明显是错误的，但我认为有更恰当的处理方式：应当隐藏这些日期信息，然后可以与用户手动显示被隐藏信息的按钮进行联动。当左上角的股票代码和股票日期被用户确认显示时，下方时间轴的日期信息就可以同步显示。"（实测截图：轴显示 2019-08/2019-11/2020-01 等偏移假日期标签且顺序错乱——RF-05「轴保留偏移假日期」默认方案被用户明确推翻。）
- RF2-03："随机模式训练结束后，用户不能从到期结算页面看到股票名称信息，只能看到训练区间信息。我认为，用户训练完成后，应该及时向用户披露自己随机到的股票是哪只，所以这里要进行修改。"

## 关键口径决策（proposed_default / 技术方案）

- **轴遮蔽形态**：遮蔽期 X 轴刻度文本为空串（轴/刻度线保留，仅日期文本隐藏）；十字线底部日期标签与画线端点轴标签（klinecharts 同走 formatDate 的 crosshair 分支）用星号遮蔽符 `******`（与 RF-05 星号遮蔽同语言）；悬浮信息卡日期行同口径（遮蔽期 `******`）。
- **揭示换算**：常量差＝`Date.parse(reveal.startDate) − Date.parse(运行中 training.startDate)`（天）；作用于时间戳（轴/十字线）与日期串（悬浮卡，支持 `YYYY-MM-DD` 与月键 `YYYY-MM`）。换算仅 gate 在「运行中 + hideTime + 已揭示」；结束态换算归零且 load 已换真实 bars，无双算。
- **定制点**：klinecharts v10 `chart.setFormatter({ formatDate })`（init 后注入一次；Chart 侧 setFormatter 走 `_setOptions` 全量 layout，含 X 轴刻度重建，props 变化时重设即重绘）；默认分支 `utils.formatDate(dateTimeFormat, timestamp, template)`＝库内默认函数 `formatTimestampByTemplate`，非随机会话/回放零行为差。
- **结算面板标的行**：无条件显示（结束态 name/code 恒真实：随机＝遮蔽层退场、盲训＝masked 仅 running）；`--` 占位仅防旧数据空值。
- **放弃路径**：既有 UX 无结算面板（confirmEnd 后 emit('ended') 返回首页），真实标的经录像库标注/历史列表/成绩单头部披露（RF-05 既有能力），本任务不改该流程。
