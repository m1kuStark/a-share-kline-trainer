## 已冻结判断（口径）

- FINANCE(3)＝品种类型：按证券代码前缀派生（60/00→1 沪深主板 A 股；688/689→科创板；300/301→创业板；8xx/4xx/92x→北交所——与工作区公式域 FINANCE(3)=1 主板过滤口径一致）；**其余 FINANCE 编号＝显式「未实现」人话错误**（不静默返回假值）。
- NAMELIKE('ST')/CODELIKE('688')＝名称/代码**前缀**匹配（通达信口径）；作用于序列上下文＝布尔常数序列。
- HYBLOCK＝当前股票所属行业名（常数序列；无行业数据＝人话错误）；HY_INDEXC/V/A＝行业指数收盘/量/额，**按股票日线日期对齐**（指数缺该日→NaN，比较为假不崩溃——与跨周期 warmup NaN 语义一致）。
- 无 StockContext 注入时调用上下文函数＝人话运行时错误（提示需注入；引擎独立使用可测）。

## root 预判定（proposed_default）

- 服务端接口形态：GET /api/formulas/context?code=600519 → { code, name, industry: { name, blockCode, indexCode } | null, industryIndexBars: MarketData[] | null }；行业文件缺失→industry null＋bars null（人话 reason），不 500。
- 指数代码派生：blockCode→sh880xxx 映射规则以 tdxzs3.cfg/tdxhy.cfg 实测结构为准（worker 核实 industry.ts 既有 IndustryEntry 字段）。
- 读取 880 日线复用 .day 读取器（若读取器有股票白名单限制则最小扩展并披露）。
- e2e 不新增（纯数据接口＋引擎函数，服务端测试＋既有 corpus 冒烟覆盖；allowed 中 e2e 文件仅允许 corpus 相关微调）。
