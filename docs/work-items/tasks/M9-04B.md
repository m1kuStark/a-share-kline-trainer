## 冻结口径

- 入口：设置弹层（训练默认设置）分栏「公式指标」，与既有分栏同导航；不新增顶层页面/路由。
- 组件：`FormulaSettings.vue` 自包含 API 调用、状态、样式；`TrainingSettings.vue` 只加 nav 按钮、activeSection 值与组件挂载。
- 列表：名称、主图叠加/副图指标、内置/停用徽标、未来函数标记；点击载入编辑。
- 校验：调用 `POST /api/formulas/validate`，成功显示「✓ 校验通过」（含未来函数清单）；失败显示中文错误（含行/列）；全角标点等 warnings 独立列出，不静默改写。
- 预览：调用 `POST /api/formulas/evaluate`（只读）——有进行中训练用 trainingId，否则用预览证券代码走通达信日线（响应注明不复权）；最多绘制 4 条输出线 SVG，标注线名与末值。
- 保存：新建/更新均先由服务端校验；错误/重复名（409）显示业务原因；保存后列表刷新。
- 删除：二次点击确认；内置公式不可删除/改源码（服务端 403 呈现）。
- 中文名可保存（跨公式引用仍要求被引用名纯英文，UI 提示）；名称/说明/源码长度边界由服务端校验。

## 行为

- 关闭设置重开后公式列表仍在（SQLite 持久化）。
- 校验失败时不会保存；保存失败保留用户输入并显示原因。
- 预览无数据/未连接通达信时显示人话错误，不崩溃。
- 键盘：Esc 关闭设置沿用既有语义；表单控件可聚焦。
