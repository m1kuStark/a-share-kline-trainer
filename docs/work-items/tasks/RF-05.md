## 背景（oracle）

用户原话（2026-10-08 验收反馈）："建议不要用文字形式写'随机标的 · 已隐藏'来隐藏股票名称和股票代码信息，这不符合一般的隐藏信息的显示方式，请借鉴很多登录系统都使用的密码输入时的信息隐藏方式，默认使用 * 符号隐藏信息，但是可以提供一个小眼睛按钮，用户可以手动选择显示该信息，选择显示时需要询问用户是否确认显示信息。而且需要注意用户选择的随机模式下，随机的方式，如果是全随机，那么股票名称代码与训练日期都要隐藏，只显示剩余未推进 K 线的根数；如果是只随机股票，那么只需要隐藏股票名称代码，日期正常显示即可；如果是随机的日期，那么隐藏训练日期，显示剩余 K 线数量即可，不需要隐藏股票名称代码。随机模式下训练结束 (包括提前结算情况) 时，将隐藏的信息进行披露，让用户最后结算的时候就能够知道，自己训练的股票和训练的时间段。随机模式的训练录像要正常保留，进入排行和历史数据中，但是要加一个 tag，让用户知道该记录是随机模式下的录像"；"录像模式下没必要隐藏股票信息了，正常显示即可，信息隐藏仅限于随机模式的训练过程中即可"。

矩阵 4 条 planned 行（架构师已立）：RAND-UI-MASK-STARS / RANDOM-HIDE-TIME-REMAINING / RANDOM-REVEAL-MIDRUN / RANDOM-REPLAY-TAG。

## 关键口径决策（proposed_default，详见验证记录）

- **「隐藏日期」边界＝信息呈现层**：训练页头部当前日期、详情起始/当前/计划结束、推进消息不显示日期，代之以剩余根数；**K 线图 X 轴日期标签保留（偏移假日期）**——轴日期是训练可用性基础，偏移假日期本就是防认股机制、不泄露真实时间；服务端偏移机制保留（矩阵 RANDOM-HIDE-TIME-OFFSET 的 binding_note 明示「偏移机制可保留在服务端响应层」）。
- **reveal 端点语义**：POST /api/trainings/:id/reveal，仅运行中随机会话有效（结束态 409 RANDOM_REVEAL_UNAVAILABLE——结束端点本就揭晓；经典训练 409；未知 id 404；非整数 id 400）；返回 `{ training: { id, code, name, startDate, plannedEnd, currentDate } }`；onSend 遮蔽层显式排除该 URL（否则揭示结果会被遮蔽层洗掉）。揭示是一次性读取：不改变其余端点的遮蔽。
- **remainingBars 口径**：`range_bar_count − equity_curve 去重日期数`（equity_curve 按 (training_id, date) 唯一入账，创建即 1 点、每推进日 +1，open_close 阶段切换/交易为 upsert 不增行）；random 对象携带于一切运行中随机会话响应（random_stock 也携带，前端仅 hideTime 时消费）。
- **回放真实信息技术方案**：不新增录像元数据、不改录像格式——回放从录像内 `resources.trainingMeta` 的**终末无 random 字段条目**（结算/放弃后检查点＝服务端已揭晓的真实值）离线派生真实标的/区间/tag；隐藏时间会话的逐日文本标签按「首个 hideTime 元信息起始日 ↔ 真实起始日」的常量差换算真实日期（等价于反向去偏移）；图表 X 轴保持录制时呈现。放弃路径配套修复：Training.vue abandon 改接服务端响应（此前只本地 patch status，随机放弃局的终末检查点会停留在遮蔽态）。
- **录像库标注**：RecordingLibrary 按 trainingKey 前缀（＝训练 id）best-effort GET /api/trainings/:id 标注真实标的＋「随机模式」tag（range.mode==='random'）；训练已删除/服务不可达时保持既有信息量。导入的分享录像在本地无对应训练时不标注（离线回放仍由录像内终末元信息揭示）。
