## 门禁清单（派发简报冻结）

1. 开卡即 gate-report 登记；task-manifest 锚定。
2. CI 矩阵收窄后 workflow 语法可解析（YAML 有效、其余步骤不动：Node 版本、缓存、test-results 上传保留）。
3. dependabot 收编：npm ls/audit 前后对照；source-map-js ≥1.2.2；shell-quote 升至审计建议安全版；两包告警清零；不新增直接依赖。
4. `npm test` 全量（存量 flaky 逐名）；`npm run build`；`npm ci --dry-run`（lockfile 一致性）。
5. 提交（chore/ci 前缀）→ push → WebFetch 轮询 actions runs 至本提交 conclusion（间隔 60~90s，最多 15 分钟）：预期 windows-latest success、无 ubuntu 任务。仍红则读 run 页修复再推，最多 2 轮。
6. 验证记录（诊断时间线引用 ai-harness-lab/dialogue/batch-20261007-ci-tracker.md）＋卡 review＋docs:status 生成器＋gate-report（含 ci-windows=0/1）。

## 冻结约束（派发简报）

- 禁止改动：server/**、web/**、desktop/**、scripts/**、测试语义、新增直接依赖。
- sprintf-js/electron-builder 链告警（moderate，修复需破坏性降级 electron-builder@26.5.0）超出本任务范围：只登记呈报，不动。
- actions 版本升级（checkout@v5 等消 Node20 警告）留用户拍板，本轮不动。
- Windows→GitHub 偶发重置：push 失败等 60s 重试最多 3 次。
- 本任务无测试语义变更：变异抽检以「CI 收窄生效证据」（新 run 无 ubuntu 任务）替代。
