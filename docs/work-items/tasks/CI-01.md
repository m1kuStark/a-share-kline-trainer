## 门禁清单（派发简报冻结）

2. CI 矩阵收窄后 workflow 语法可解析（YAML 有效、其余步骤不动：Node 版本、缓存、test-results 上传保留）。

## 冻结约束（派发简报）

- 禁止改动：server/**、web/**、desktop/**、scripts/**、测试语义、新增直接依赖。
- sprintf-js/electron-builder 链告警（moderate，修复需破坏性降级 electron-builder@26.5.0）超出本任务范围：只登记呈报，不动。

- 本任务无测试语义变更：变异抽检以「CI 收窄生效证据」（新 run 无 ubuntu 任务）替代。
