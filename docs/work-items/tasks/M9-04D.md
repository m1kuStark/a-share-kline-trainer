## 冻结口径

- 3 个内置示例（builtin=1，启动幂等 seed，按 name 冲突不覆盖）：
  1. WEEK_MACD_SUB（副图）：周线 MACD 三线，跨周期引用 "MACD.DIF#WEEK" 等；
  2. MA_BULL_MAIN（主图）：MA5/10/20/60 多头排列参考；
  3. QINIU_B1_SUB（副图）：DIF/DEA 与 B1 金叉信号。
- seed 入口在 server/src/index.ts（migrateDatabase 之后），不走 DB 迁移；测试可显式调用 seedBuiltinFormulas。
- 内置公式：UI 显示内置徽标；服务端禁止改名/改源码/删除（既有 403 保护）；可禁用。
- CLI scripts/formula-agent.mjs：list/validate/evaluate（source 或 formulaId + trainingId/code/limit），只读，输出 JSON；默认 base URL http://127.0.0.1:8787，可 --base 覆盖；错误退出码非 0 并输出人话。
- 文档 docs/engineering/formula-agent-api.md：HTTP 契约、错误码、curl 与 CLI 示例、只读边界（不写训练/画线/下单）、随机训练遮蔽说明。
- e2e：设置「公式指标」列表可见内置示例（至少一个），且不可删除（无删除按钮）。

## 行为

- 重启/升级幂等：不重复插入、不覆盖用户数据；删除内置公式接口返回 403。
- 内置示例可在图表（主图/副图）渲染与预览（依赖 A/B/C 能力）。
- CLI 只读：不产生训练/画线/下单写操作；validate 失败退出码非 0 且输出 kind/line/column。
