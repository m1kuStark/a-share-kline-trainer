## 核心口径（验收追认＋修订决策）

| 口径 | 内容 |
|---|---|
| 交易 | 当日收盘价成交；T+1；整手 100 股；买入仓位按总权益（受现金约束取整到手）；费率可开佣金万 2.5 最低 5 元＋卖出印花税 0.05% |
| 权息 | 分红入现金/送转加股/配股足额自动缴款（权息入账持仓，验收追认）；成交价换算图表空间 chartPrice 防跨除权错位 |
| 复权 | 默认前复权，创建时锁定；基准滚动到推进日（防未来） |
| 可见历史 | 420 同屏最大可见根数语义（非加载总量）；初始载 620；缩放 1~420；动态历史 forward 前插 |
| 排行 | 收益率→最大回撤→胜率三级字典序；提前结算打标单独分组 |
| 双盲 | 移出 V1（手动选股下隐藏名称无意义）；V2 候选＝随机股票＋随机时间真盲测 |
| 画线 | 工具链范围见 docs/M3-画线工具链-开发计划.md（D1~D32 单元）；默认 1px 虚线黄色 dashedValue[4,4]；多选标识天蓝色；文本不做绝对定位 |
| 编辑 | 颜色/粗细(1~5px)/样式(实线/虚线/点线)/端点价位（两位小数，不编辑横坐标）；多选选项卡式批量编辑 |
