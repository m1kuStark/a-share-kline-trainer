# 按交易日回放

SessionReplay消费已校验v1/v2文件，v1只迁移一次。[dailyReplay](../recording/dailyReplay.ts)按元数据建稀疏索引，CompactReader按需解码，不展开全会话。

## 时间轴与数据

已接受推进事件建立日分界，结算没有新K线不加日。延迟捕获不生成重复日，暂停中跳日按真实观察日期分段并保留缺口。每日本日末之前的安全检查点提供账户与图表。旧周/月快照缺日线时首屏立即回退并提示；盲训不能把上一日数据当今日。周/月只从当前已见日线本地聚合，不按当前TDX重算旧价格。

## 播放与观察

上一日/下一日和空格推进一个已录交易日。间隔0.2/0.5/1/2/5/10秒，单计时器、末日停止、卸载清理。中括号切周期、上下缩放、左右十字线和Home最新在播放或暂停时都可用；输入及组合键隔离，B/S/Delete不写数据。

普通日期/周期不重建图表；画线版本变化时捕获用户视窗，重挂恢复本日图形再还原视窗。单根K线缩放按柱宽，仍受同屏和柱宽边界约束。

业务列表复用businessEvents，完成买卖或图形文字变更只显示一次；拒单/失败/未知标注，取消、中断补齐、主题/工具/保存不算业务操作。最多100项窗口，点击定位当天，缺口常驻。只读回放不重新成交，不代表交易引擎确定性重算。

入口为首页和侧栏训练录像库。测试见[日回放](../../../e2e/recording-daily.spec.ts)，用户验收以任务卡为准。
