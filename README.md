# A股K线训练器（kline-trainer）

离线的A股K线逐日训练工具：读取你电脑里已有的通达信日线数据，逐日推进行情，练习判断、下单和画线，结束后查看这笔训练的成绩与复盘。界面为中文，K线红涨绿跌。当前版本 **v1.2.7**。

这是个人训练工具，不是券商交易软件，没有自动交易，也不提供投资建议。

## 核心能力

- **逐日训练**：自选股票与区间（1M/3M/6M/1Y/2Y 或自定义起止），设定初始资金，空格推进；支持开盘/收盘两阶段训练时钟——开盘阶段只见开盘价，不泄露当天完整K线。T+1、整手100股、费用按本局规则快照执行，可提前结算或到期结算。
- **统一下单面板**：普通下单/条件单两个标签页共享百分比仓位与按股数买卖；普通单按当前阶段价成交，条件单**到价才触发**（方向按挂单时价格位置冻结），支持同时挂多笔、在途资金/持仓占用校验。条件单在开盘阶段按开盘价成交，限价有价格保护；收盘阶段限价按触发价、止损按收盘价成交，挂单理由与最近记录可查。
- **图表**：日/周/月周期，MA(25/60/144)、VOL、MACD，23种画线工具随训练保存；默认前复权显示，阶段价位线红涨绿跌。
- **录制与回放**：训练操作默认录制、可暂停；录像库按安装实例隔离，并将本机训练录像与导入的分享录像分栏展示；支持导出、导入、单条删除和按来源清理，导入录像不会混入本机训练记录。
- **成绩与复盘**：结算历史、五档周期/自定义区间/行业/单股排行（总收益率、最大回撤、胜率、盈亏比、同期沪深300超额），浮窗成绩单含逐笔成交与权益曲线，可叠加上证指数、国证 2000 对比。
- **数据本地化与版本独立**：只读取你本机通达信目录的日线和权息文件，不联网下载行情，安装包不含任何市场数据；训练数据默认保存在安装目录下的 `data` 文件夹，不同版本安装目录的训练数据相互独立，也可在设置中自定义保存路径。
- **接入与设置**：首次接入通过 Windows 原生目录选择器确认通达信目录，校验通过后保存并连接；训练默认资金/复权/费用/T+1、自动检查偏好、快捷键自定义；设置按"默认设置、偏好设置、数据目录"分栏。

## 快速开始（Windows）

1. 到 [Releases](https://github.com/m1kuStark/a-share-kline-trainer/releases) 下载最新版 `kline-trainer-v<版本>-windows-x64.zip`。安装包自带运行环境，**无需安装 Node、npm 或 Python，无需账号**。
2. 右键完整解压到一个固定文件夹（之后不要移动它）。
3. 双击 `Start.cmd`，浏览器自动打开本机地址。首次使用按向导配置通达信安装目录，并在通达信里下载目标股票的日线数据。
4. 选股票、选区间、开始训练：空格推进下一日，B/S 买卖，`[` `]` 切换周期，Home 回到最新。
5. 双击 `Create Shortcut.cmd` 创建桌面图标，以后从图标启动。

程序只监听本机 `127.0.0.1`，不对外网开放。详细步骤与配置字段见[安装与配置](docs/user/install.md)。

## 从源码运行

需要 Node 24 与 npm 10+：

```powershell
npm ci
npm run build
npm start
```

环境变量示例（PowerShell）：`$env:TDX_ROOT='D:\path\to\tdx'`、`$env:PORT='8787'`、`$env:TRAINER_DB='D:\data\trainer.sqlite'`。开发与测试说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。
