# A股K线训练器（kline-trainer）

离线的A股K线逐日训练工具：读取你电脑里已有的通达信日线数据，逐日推进行情，练习判断、下单和画线，结束后查看这笔训练的结果。界面为中文，K线红涨绿跌。

本页描述 `wt/integration/v1` 的 V1.2.1 修订候选（2026-10-01 核对），当前仍待最终包检查和用户验收。V1.2.1 在 V1.2.0 基础上修复阶段价位线、条件单股数校验、长按快捷键、股票目录缓存和应用内退出生命周期，并继续保留历史、成绩单、录像和设置边界。源码、安装包和用户验收状态分别确认，见[当前开发状态](https://github.com/m1kuStark/kline-trainer/blob/main/docs/status.md)。

源码候选能做什么：

- **逐日训练**：自选股票与区间（1M/3M/6M/1Y/2Y）和初始资金，按空格逐日推进，按当日收盘价成交，T+1、整手100股，可提前结算或到期结算。
- **图表**：日/周/月周期，MA、VOL、MACD，23种画线工具并随训练保存；默认前复权显示。
- **录制与回放**：训练操作默认录制、可暂停；导出压缩文件分享，对方用本工具导入即可逐步回放，不依赖你本机的数据路径。
- **数据本地化**：只读取你本机通达信目录里的日线和权息文件，不联网下载行情，安装包也不含任何市场数据。
- **成绩与复盘**：结算历史、可删除记录、浮窗成绩单、收益率坐标轴与可选上证/国证 2000 对比、五档/自定义区间/行业/单股排行、最大回撤/胜率/盈亏比/沪深300超额；成绩单 K 线复盘展示暂缓，既有画线事实保留供后续方案使用。
- **接入与设置**：用户确认式通达信目录选择、保存退出、训练默认资金/复权/费用/T+1、自动检查偏好与 TDX 路径设置；默认只影响新训练，数据目录保存后重启生效。设置页按默认设置、偏好设置、数据目录分栏，未连接状态可从右上角直接打开 Windows 原生目录选择器。

这是个人训练工具，不是券商交易软件，没有自动交易，也不提供投资建议。候选门禁和用户验收见任务记录；旧版行情保存原语尚未接入训练读取，不能保证已有训练固定使用历史行情版本。

## 公开版本下载（Windows，v0.3.2）

1. 到 [Releases](https://github.com/m1kuStark/kline-trainer/releases) 下载 `kline-trainer-v0.3.2-windows-x64.zip`。安装包自带运行环境，**无需安装 Node、npm 或 Python，无需订阅、模型或账号**。
2. 右键完整解压到一个固定文件夹（之后不要移动它）。
3. 双击 `Start.cmd`，浏览器自动打开 `http://127.0.0.1:8787`。程序会检查少数预设通达信目录；能搜索到股票并加载行情时，可以直接开始训练。
4. 若提示未连接通达信或缺数据，按[安装说明](docs/user/install.md)配置目录并在通达信下载日线。v0.3.2 仍需手动配置未被发现的安装路径；自动发现和引导式接入尚未作为发布功能提供。
5. 双击 `Create Shortcut.cmd` 创建桌面图标，以后从图标启动。

程序只监听本机 `127.0.0.1`，不对外网开放。详细步骤与配置字段见[安装与配置](docs/user/install.md)。

## V1.2.1 更新（源码候选，待人工验收）

- 开盘/收盘训练阶段显示当前阶段价位线；open 阶段不泄露当天完整 OHLC。
- 条件单提交前校验可用资金、可卖持仓和 T+1 限制；主图价格轴显示 pending 条件单触发点。
- 空格、缩放和十字光标方向快捷键允许浏览器长按连续触发，输入框/弹窗/画线取点继续隔离。
- 股票目录索引在内存复用，显著降低连续检索的磁盘扫描开销。
- 应用内退出允许保留未结算训练，后台等待会取消本次协调；退出失败后可以重新发起。

## V1.2.0 更新（源码候选，待人工验收）

- 通达信目录选择器绑定浏览器前台窗口，选择期间阻断训练器页面操作；退出先取消活动选择器，失败后可重试，不再一直停在“正在退出”。
- 成绩单浮窗适配深浅主题，只保留一个关闭出口，标题移除“第 N 局”，本局规则改为简洁标签。
- 训练收益率（红色）、上证指数（蓝色）和国证 2000（橙色）共享一张对比图，增加底部日期轴、右侧百分比轴和悬停提示；基准复选框分别控制对应曲线。

## V1.1.0 更新（历史候选，未公开发布）

- 自定义范围改为起始日＋结束日；未来或反向日期会提示修正，服务端仍负责最终校验，旧的 bars/latest 请求保持兼容。
- 未连接通达信时，右上角按钮直接打开 Windows 原生目录选择器；设置页改为默认设置、偏好设置、数据目录三栏，数据目录支持 Windows 原生文件夹选择。
- 当前候选已完成定向单测、类型检查、生产构建和隔离 Journey；Windows 包、全量门禁和用户验收状态见[当前开发状态](https://github.com/m1kuStark/kline-trainer/blob/main/docs/status.md)。
- 顶部通达信入口不再自动扫描，直接打开 Windows 原生目录选择器；连接失败保留原配置并显示可行动状态。
- 历史记录支持确认后单条/批量删除；成绩单改为可关闭浮窗，移除独立画线清单，收益率曲线可叠加上证指数和国证 2000（数据缺失时明确不可用）。
- 排行增加严格按起止日期分组的自定义区间视图和显式 56 行业目录视图；行业目录缺失时不猜测归属。

## v0.3.3 更新（测试版，未公开发布）

- 创建训练时保存费用、T+1 等交易规则快照；本局执行按快照数值驱动，旧训练保持兼容（见[训练规则](docs/user/training-rules.md)）。
- 训练范围新增"到最新日线"与"自定义日K根数"模式：周期预设联动起始日，创建前显示请求区间、实际首末日与调整原因。
- 数据新鲜度接入官方日历来源，修复盘后新鲜度误判。
- B/S 标记支持成交明细浮层；通达信候选诊断、受保护排空与重启计划已集成。V1 候选在此基础上扩展历史、排行、向导与设置。

## v0.3.2 更新

- 首页录像入口统一到左侧“训练录像”，导入、历史和回放路径保持一致。
- 录像回放支持按交易日推进、播放控制、日/周/月观察和离线读取；旧录像迁移与缺少当日日线的降级提示保持兼容。
- Windows 启动器和隔离运行时的停止、重复启动、取消失败记录更加明确，无法证明整棵进程树退出时会保留诊断信息。
- 当前版本仍只读取本机通达信文件，不联网下载行情；通达信路径仍按安装说明配置。

## 从源码运行

需要 Node 24 与 npm 10+：

```powershell
npm ci
npm run build
npm start
```

环境变量示例（PowerShell）：`$env:TDX_ROOT='D:\path\to\tdx'`、`$env:PORT='8787'`、`$env:TRAINER_DB='D:\data\trainer.sqlite'`。开发与测试说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。
